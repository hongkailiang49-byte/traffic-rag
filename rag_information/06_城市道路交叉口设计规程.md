# 城市道路交叉口设计规程

## 一、规程概述

《城市道路交叉口设计规程》（CJJ 152-2010）是中华人民共和国住房和城乡建设部发布的行业标准，于2010年发布实施。该规程适用于城市道路交叉口的规划、设计和建设，是城市道路交叉口设计的基本技术依据。

该规程的制定目的是规范城市道路交叉口设计，提高交叉口通行能力和交通安全水平，优化城市道路网络功能。

## 二、交叉口分类与等级

### （一）按交通组织方式分类

**1. 平面交叉口**
- 无信号控制交叉口
- 信号控制交叉口
- 环形交叉口

**2. 立体交叉口**
- 分离式立交
- 互通式立交

### （二）按交叉形式分类

**1. T形交叉口**
- 三路交叉
- 适用于主次道路相交

**2. 十字形交叉口**
- 四路交叉
- 最常见的交叉形式

**3. Y形交叉口**
- 锐角三路交叉
- 需要特殊渠化设计

**4. X形交叉口**
- 多路交叉
- 交通组织复杂

**5. 环形交叉口**
- 车辆绕中心岛行驶
- 适用于中小交通量

**6. 错位交叉口**
- 两条T形交叉口错位布置
- 需要协调设计

### （三）交叉口等级划分

根据相交道路等级，交叉口分为以下等级：

| 交叉口等级 | 相交道路 | 功能定位 |
|-----------|---------|---------|
| A级 | 快速路与快速路 | 枢纽型交叉口 |
| B级 | 快速路与主干路 | 快速路出入口 |
| C级 | 主干路与主干路 | 主要交叉口 |
| D级 | 主干路与次干路 | 一般交叉口 |
| E级 | 次干路与支路 | 次要交叉口 |
| F级 | 支路与支路 | 一般交叉口 |

## 三、平面交叉口设计

### （一）交叉口形式选择

**选择原则：**
- 与相交道路等级和功能相适应
- 满足交通流量和流向需求
- 考虑用地条件和周边环境
- 便于行人和非机动车通行

**形式选择建议：**

| 相交道路等级 | 推荐形式 | 备选形式 |
|------------|---------|---------|
| 主干路与主干路 | 信号控制交叉口 | 分离式立交 |
| 主干路与次干路 | 信号控制交叉口 | 环形交叉口 |
| 次干路与支路 | 信号控制交叉口 | 无信号控制交叉口 |
| 支路与支路 | 无信号控制交叉口 | 环形交叉口 |

### （二）交叉口几何设计

**1. 交叉口转角半径**

| 相交道路等级 | 转角半径（m） |
|------------|--------------|
| 主干路与主干路 | 15～25 |
| 主干路与次干路 | 12～20 |
| 次干路与支路 | 8～15 |
| 支路与支路 | 5～10 |

**2. 交叉口车道数**

- 进口道车道数应大于等于路段车道数
- 出口道车道数应大于等于进口道车道数
- 进口道增加车道数宜为1～2条

**3. 进口道展宽**

| 设计速度（km/h） | 最小展宽长度（m） | 渐变段长度（m） |
|-----------------|-----------------|----------------|
| 60 | 80 | 30 |
| 50 | 60 | 25 |
| 40 | 50 | 20 |
| 30 | 40 | 15 |

**4. 车道宽度**

| 车道类型 | 宽度（m） |
|---------|----------|
| 直行车道 | 3.25～3.50 |
| 左转车道 | 3.00～3.25 |
| 右转车道 | 3.00～3.50 |
| 公交专用道 | 3.50～3.75 |

### （三）渠化设计

**1. 渠化目的**
- 分离冲突交通流
- 引导车辆行驶轨迹
- 减少冲突点数量
- 提高交叉口安全性

**2. 渠化方式**

| 渠化方式 | 适用条件 | 设置要求 |
|---------|---------|---------|
| 导流岛 | 右转车辆较多 | 设置在进口道右侧 |
| 分隔带 | 对向车流分离 | 设置在道路中央 |
| 导向线 | 车道导向 | 设置在车道内 |
| 转弯渠化 | 左右转车辆引导 | 设置在交叉口内 |

**3. 导流岛设计**

| 设计速度（km/h） | 最小面积（m²） | 最小长度（m） |
|-----------------|---------------|--------------|
| 60 | 8.0 | 8.0 |
| 50 | 6.0 | 6.0 |
| 40 | 4.0 | 4.0 |
| 30 | 2.0 | 2.0 |

### （四）行人与非机动车过街设施

**1. 人行横道设计**

| 设计参数 | 要求 |
|---------|------|
| 宽度 | 不小于4m，人流密集处不小于6m |
| 设置位置 | 距交叉口转角不小于5m |
| 转弯半径 | 不小于6m |
| 信号配时 | 应满足行人过街时间需求 |

**2. 非机动车过街设计**

- 应设置非机动车过街通道
- 通道宽度不小于3m
- 应与人行横道分离或协调设置

**3. 无障碍设计**

- 应设置缘石坡道
- 坡道坡度不大于1:12
- 应设置盲道引导

## 四、信号控制交叉口设计

### （一）信号控制类型

| 控制类型 | 适用条件 | 特点 |
|---------|---------|------|
| 定时控制 | 交通流量稳定 | 配时固定 |
| 感应控制 | 交通流量变化大 | 配时自适应 |
| 协调控制 | 干道绿波 | 多交叉口协调 |
| 区域控制 | 路网交通优化 | 区域协调 |

### （二）信号相位设计

**1. 相位数选择**

| 相交道路等级 | 推荐相位数 | 说明 |
|------------|-----------|------|
| 主干路与主干路 | 4相位 | 左转专用相位 |
| 主干路与次干路 | 2～4相位 | 根据左转流量确定 |
| 次干路与支路 | 2相位 | 简单相位 |

**2. 相位顺序设计**

- 应考虑行人过街安全
- 应减少冲突点
- 应提高绿灯利用率

### （三）信号配时基本参数

| 参数 | 说明 | 取值范围 |
|------|------|---------|
| 周期时长 | 一个信号周期的总时长 | 60～180s |
| 绿灯时间 | 各相位绿灯时长 | 根据交通量计算 |
| 黄灯时间 | 黄灯时长 | 3～5s |
| 全红时间 | 清空交叉口时间 | 2～3s |
| 行人绿灯 | 行人过街绿灯时长 | 根据过街距离计算 |

### （四）交叉口视距要求

| 设计速度（km/h） | 停车视距（m） | 安全视距三角形边长（m） |
|-----------------|--------------|----------------------|
| 60 | 75 | 75 |
| 50 | 60 | 60 |
| 40 | 40 | 40 |
| 30 | 30 | 30 |

## 五、立体交叉口设计

### （一）立交类型选择

**1. 分离式立交**
- 两条道路立体交叉，不设连接匝道
- 适用于交通量大、用地受限的情况

**2. 互通式立交**

| 立交类型 | 适用条件 | 通行能力 | 用地面积 |
|---------|---------|---------|---------|
| 苜蓿叶型 | 四路交叉，用地充足 | 中等 | 大 |
| 喇叭型 | 三路交叉 | 中等 | 中等 |
| 环形 | 多路交叉 | 中等 | 中等 |
| 菱形 | 主干路与次干路 | 较高 | 较小 |
| 半定向型 | 交通量大 | 高 | 较大 |
| 全定向型 | 交通量很大 | 很高 | 大 |

### （二）匝道设计

**1. 匝道类型**

| 匝道类型 | 特点 | 适用条件 |
|---------|------|---------|
| 直接式 | 车辆直接转向 | 交通量大 |
| 半直接式 | 车辆部分绕行 | 交通量中等 |
| 环形匝道 | 车辆绕行 | 交通量小 |

**2. 匝道技术指标**

| 设计参数 | 推荐值 |
|---------|--------|
| 设计速度 | 30～60km/h |
| 最小平曲线半径 | 30～100m |
| 最大纵坡 | 4%～6% |
| 车道宽度 | 3.0～3.5m |

### （三）净空要求

**1. 净空高度**

| 交叉类型 | 最小净空高度（m） |
|---------|-----------------|
| 机动车道 | 4.5 |
| 非机动车道 | 3.5 |
| 人行道 | 2.5 |

**2. 净空宽度**

- 应满足车辆行驶轨迹要求
- 应考虑安全余量

## 六、交通信号控制设施

### （一）信号灯设置

**1. 信号灯类型**

| 信号灯类型 | 用途 | 设置位置 |
|-----------|------|---------|
| 机动车信号灯 | 控制机动车 | 进口道上方或右侧 |
| 非机动车信号灯 | 控制非机动车 | 进口道右侧 |
| 人行横道信号灯 | 控制行人 | 人行横道两端 |
| 方向指示信号灯 | 指示转向 | 进口道上方 |

**2. 信号灯安装要求**

| 安装参数 | 要求 |
|---------|------|
| 安装高度 | 5.5～7.0m（悬臂式） |
| 可视距离 | 不小于150m |
| 安装位置 | 进口道右侧或上方 |

### （二）交通标志设置

- 在交叉口入口前设置预告标志
- 在交叉口内设置导向标志
- 在出口处设置确认标志

### （三）交通标线设置

- 设置车道分界线
- 设置导向箭头
- 设置停止线
- 设置人行横道线

## 七、特殊交叉口设计

### （一）多路交叉口

- 交通组织复杂
- 宜采用环形交叉或信号控制
- 必要时应调整路网，减少多路交叉

### （二）错位交叉口

- 两个T形交叉口错位布置
- 应协调两个交叉口的信号配时
- 宜设置中央分隔带，规范左转车辆

### （三）畸形交叉口**

- 交叉角度过小或过大
- 应进行渠化设计
- 必要时调整道路线形

### （四）公交优先交叉口

- 设置公交专用进口道
- 配置公交信号优先系统
- 优化公交停靠站位置

## 八、交叉口设计流程

### （一）前期调研

1. 交通流量调查
2. 现状问题分析
3. 用地条件评估
4. 周边环境调查

### （二）方案设计

1. 确定交叉口形式
2. 进行几何设计
3. 设计渠化方案
4. 设计信号配时

### （三）详细设计

1. 绘制设计图纸
2. 编制设计说明
3. 计算工程数量
4. 编制工程预算

### （四）设计审查

1. 技术审查
2. 安全评估
3. 方案优化
4. 批准实施
