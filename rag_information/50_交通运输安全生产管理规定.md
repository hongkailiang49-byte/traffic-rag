# 交通运输安全生产管理规定

## 一、概述

《交通运输安全生产管理规定》（交通运输部令2023年第12号）于2023年11月发布，自2024年1月1日起施行。该规定是交通运输部为加强交通运输行业安全生产管理而制定的部门规章，适用于道路运输、水路运输、城市公共交通、公路水运工程建设等领域的安全生产管理。

该规定旨在贯彻落实《安全生产法》等法律法规，强化交通运输行业安全生产责任，预防和减少生产安全事故，保障人民群众生命财产安全。规定共八章，包括总则、安全生产责任、安全生产条件、安全生产管理、安全生产监督、事故报告与处理、法律责任和附则。

近年来，我国交通运输安全生产形势总体稳定，但重特大事故时有发生，安全生产基础仍然薄弱。该规定的出台，对于完善交通运输安全生产管理体系，提升安全生产管理水平，具有重要意义。

## 二、基本原则

### 2.1 "三管三必须"原则

**管行业必须管安全：**
- 交通运输主管部门在履行行业管理职责时，必须同步履行安全生产监管职责
- 将安全生产纳入行业发展规划
- 将安全生产纳入行业管理制度
- 将安全生产纳入行业考核体系

**管业务必须管安全：**
- 交通运输各业务部门在开展业务工作时，必须同步落实安全生产要求
- 在业务审批中落实安全生产条件
- 在业务监管中检查安全生产状况
- 在业务考核中评估安全生产绩效

**管生产经营必须管安全：**
- 交通运输生产经营单位在开展生产经营活动时，必须同步落实安全生产主体责任
- 建立安全生产责任制
- 保障安全生产投入
- 加强安全生产管理

### 2.2 其他基本原则

**安全第一、预防为主、综合治理：**
- 坚持安全第一，把安全放在首位
- 坚持预防为主，把工作做在前面
- 坚持综合治理，采取多种措施

**人民至上、生命至上：**
- 把保护人民生命安全摆在首位
- 树牢安全发展理念
- 绝不能以牺牲安全为代价

**谁主管谁负责、谁审批谁负责：**
- 主管部门对本行业安全生产负责
- 审批部门对审批事项的安全性负责
- 建立安全生产责任追究制度

## 三、安全生产责任

### 3.1 交通运输主管部门责任

**行业监管责任：**
- 制定行业安全生产规章制度
- 组织开展行业安全生产检查
- 督促企业落实安全生产主体责任
- 组织开展行业安全生产培训

**具体职责：**
- 制定行业安全生产发展规划
- 建立行业安全生产标准体系
- 建立行业安全生产监管体系
- 建立行业安全生产应急体系

**监管方式：**
- 日常监管：定期对生产经营单位进行安全检查
- 专项监管：针对重点时段、重点领域开展专项检查
- 随机监管：随机抽取生产经营单位进行检查
- 重点监管：对重大危险源实施重点监管

### 3.2 企业主体责任

**主体责任内容：**
- 建立安全生产责任制
- 制定安全生产规章制度
- 保障安全生产投入
- 加强安全生产教育培训
- 建立安全风险分级管控机制
- 建立隐患排查治理机制
- 建立应急救援体系

**主要负责人责任：**
- 建立健全本单位安全生产责任制
- 组织制定本单位安全生产规章制度和操作规程
- 组织制定并实施本单位安全生产教育和培训计划
- 保证本单位安全生产投入的有效实施
- 组织建立并落实安全风险分级管控和隐患排查治理双重预防工作机制
- 及时、如实报告生产安全事故

**安全管理人员责任：**
- 组织或者参与拟订本单位安全生产规章制度、操作规程
- 组织或者参与本单位安全生产教育和培训
- 组织开展危险源辨识和评估
- 组织或者参与本单位应急救援演练
- 检查本单位的安全生产状况，及时排查生产安全事故隐患
- 制止和纠正违章指挥、强令冒险作业、违反操作规程的行为

### 3.3 全员安全生产责任制

**制度要求：**
- 建立从主要负责人到一线从业人员的安全生产责任制
- 明确各岗位的安全责任
- 建立安全生产责任考核机制
- 落实安全生产责任追究制度

**考核机制：**
- 定期对各岗位安全生产责任落实情况进行考核
- 考核结果与绩效挂钩
- 对安全生产责任落实不到位的进行问责
- 对安全生产责任落实好的进行表彰

## 四、安全生产条件

### 4.1 基本条件

**组织条件：**
- 设置安全生产管理机构
- 配备专职安全生产管理人员
- 建立安全生产管理制度
- 建立安全生产操作规程

**人员条件：**
- 主要负责人和安全生产管理人员具备相应的安全生产知识和管理能力
- 从业人员经过安全生产教育和培训
- 特种作业人员取得相应资格
- 新入职员工经过三级安全教育培训

**设施条件：**
- 生产经营场所符合安全生产要求
- 安全设施、设备符合国家标准或行业标准
- 安全防护设施齐全有效
- 应急救援器材、设备齐全有效

**资金条件：**
- 保障安全生产投入
- 安全生产费用专款专用
- 建立安全生产费用管理制度
- 定期对安全生产费用使用情况进行评估

### 4.2 道路运输安全生产条件

**客运企业条件：**
- 有与其经营业务相适应并经检测合格的车辆
- 有符合规定条件的驾驶人员
- 有健全的安全生产管理制度
- 有相应的安全生产管理人员

**货运企业条件：**
- 有与其经营业务相适应并经检测合格的车辆
- 有符合规定条件的驾驶人员
- 有健全的安全生产管理制度
- 有相应的安全生产管理人员

**危险货物运输企业条件：**
- 有符合要求的专用车辆及设备
- 有符合要求的从业人员
- 有健全的安全生产管理制度
- 有相应的安全生产管理人员

### 4.3 水路运输安全生产条件

**航运企业条件：**
- 有与其经营业务相适应并经检验合格的船舶
- 有符合规定条件的船员
- 有健全的安全生产管理制度
- 有相应的安全生产管理人员

**港口企业条件：**
- 有与其经营业务相适应的码头设施
- 有符合规定条件的从业人员
- 有健全的安全生产管理制度
- 有相应的安全生产管理人员

## 五、安全生产管理

### 5.1 安全风险分级管控

**风险辨识：**
- 辨识生产经营活动中存在的危险源
- 分析危险源可能导致的事故类型
- 评估事故发生的可能性和后果严重程度

**风险评估：**
- 采用定性或定量方法进行风险评估
- 根据风险评估结果确定风险等级
- 风险等级分为重大风险、较大风险、一般风险和低风险

**风险管控：**
- 针对不同等级的风险制定相应的管控措施
- 重大风险：制定专项管控方案，明确管控责任
- 较大风险：制定管控措施，加强监控
- 一般风险：采取常规管控措施
- 低风险：采取日常管控措施

**风险公告：**
- 在生产经营场所设置安全风险公告栏
- 在重大风险区域设置警示标志
- 向从业人员告知安全风险
- 定期更新安全风险信息

### 5.2 隐患排查治理

**隐患排查：**
- 建立隐患排查治理制度
- 制定隐患排查治理标准
- 定期开展隐患排查
- 记录隐患排查情况

**隐患分级：**
- 重大隐患：可能导致重大事故的隐患
- 一般隐患：除重大隐患外的其他隐患

**隐患治理：**
- 重大隐患：制定治理方案，明确治理责任、治理措施、治理资金、治理时限
- 一般隐患：立即整改或者限期整改

**隐患销号：**
- 隐患治理完成后，应当进行验收
- 验收合格后，予以销号
- 验收不合格的，继续整改
- 建立隐患排查治理档案

### 5.3 安全生产教育培训

**培训对象：**
- 主要负责人
- 安全生产管理人员
- 从业人员
- 新入职员工
- 特种作业人员

**培训内容：**
- 安全生产法律法规
- 安全生产规章制度
- 安全操作规程
- 应急处置知识
- 事故案例分析

**培训要求：**
- 主要负责人和安全生产管理人员初次培训时间不少于32学时，每年再培训时间不少于12学时
- 从业人员初次培训时间不少于24学时，每年再培训时间不少于8学时
- 新入职员工三级安全教育培训时间不少于24学时
- 特种作业人员应当取得相应资格

### 5.4 应急管理

**应急预案：**
- 制定综合应急预案
- 制定专项应急预案
- 制定现场处置方案
- 定期修订应急预案

**应急演练：**
- 定期开展应急演练
- 演练后进行总结评估
- 根据演练情况修订应急预案
- 提高应急处置能力

**应急物资：**
- 配备必要的应急救援器材
- 配备必要的应急救援设备
- 建立应急物资管理制度
- 定期检查应急物资状态

**应急值守：**
- 建立应急值守制度
- 重要时段实行24小时值班
- 及时报告突发事件信息
- 及时启动应急响应

### 5.5 安全生产信用管理

**信用档案：**
- 建立安全生产信用档案
- 记录守信和失信行为
- 定期更新信用信息
- 实现信用信息共享

**信用评价：**
- 开展安全生产信用评价
- 根据评价结果确定信用等级
- 信用等级分为A、B、C、D四级
- 定期公布信用评价结果

**信用惩戒：**
- 对严重失信主体实施信用惩戒
- 限制严重失信主体参与政府采购
- 限制严重失信主体享受优惠政策
- 将严重失信主体列入黑名单

## 七、事故报告与处理

### 7.1 事故报告

**报告时限：**
- 事故发生后，事故现场有关人员应当立即报告本单位负责人
- 单位负责人接到报告后，应当于1小时内向事故发生地县级以上人民政府安全生产监督管理部门和负有安全生产监督管理职责的有关部门报告
- 情况紧急时，事故现场有关人员可以直接向事故发生地县级以上人民政府安全生产监督管理部门和负有安全生产监督管理职责的有关部门报告

**报告内容：**
- 事故发生单位概况
- 事故发生的时间、地点以及事故现场情况
- 事故的简要经过
- 事故已经造成或者可能造成的伤亡人数
- 已经采取的措施
- 其他应当报告的情况

**报告方式：**
- 电话报告
- 书面报告
- 网络报告

### 7.2 事故调查

**调查权限：**
- 特别重大事故：由国务院或者国务院授权有关部门组织事故调查组进行调查
- 重大事故：由省级人民政府负责调查
- 较大事故：由设区的市级人民政府负责调查
- 一般事故：由县级人民政府负责调查

**调查程序：**
1. 成立事故调查组
2. 开展事故调查
3. 提交事故调查报告
4. 事故调查报告批复

**调查内容：**
- 事故发生的经过和原因
- 事故造成的人员伤亡和直接经济损失
- 事故的性质和责任
- 对事故责任者的处理建议
- 防止类似事故发生的整改措施

### 7.3 事故处理

**责任追究：**
- 对事故责任单位和责任人员依法给予行政处罚
- 构成犯罪的，依法追究刑事责任
- 对负有事故责任的国家工作人员依法给予处分

**整改措施：**
- 制定事故整改方案
- 落实事故整改措施
- 验收事故整改效果
- 建立事故整改档案

**信息公开：**
- 依法公开事故调查报告
- 接受社会监督
- 做好事故善后处理工作

## 八、法律责任

### 8.1 对企业的处罚

**未建立安全生产责任制的：**
- 责令限期改正
- 逾期未改正的，责令停产停业整顿
- 并处二万元以上五万元以下罚款

**未保障安全生产投入的：**
- 责令限期改正
- 逾期未改正的，责令停产停业整顿
- 并处二万元以上五万元以下罚款

**未建立安全风险分级管控机制的：**
- 责令限期改正
- 逾期未改正的，责令停产停业整顿
- 并处二万元以上五万元以下罚款

**未建立隐患排查治理机制的：**
- 责令限期改正
- 逾期未改正的，责令停产停业整顿
- 并处二万元以上五万元以下罚款

### 8.2 对个人的处罚

**主要负责人未履行安全生产管理职责的：**
- 责令限期改正
- 逾期未改正的，处二万元以上五万元以下罚款
- 导致发生生产安全事故的，给予撤职处分
- 构成犯罪的，依法追究刑事责任

**安全生产管理人员未履行安全生产管理职责的：**
- 责令限期改正
- 逾期未改正的，处一万元以上三万元以下罚款
- 导致发生生产安全事故的，给予撤职处分
- 构成犯罪的，依法追究刑事责任

### 8.3 信用惩戒

**严重失信行为：**
- 发生重大以上生产安全事故的
- 一年内发生两起以上较大生产安全事故的
- 拒不执行安全生产监管指令的
- 其他严重失信行为

**惩戒措施：**
- 列入安全生产失信联合惩戒名单
- 限制参与政府采购
- 限制享受优惠政策
- 限制获得荣誉称号

## 九、监督机制

### 9.1 行政监督

**层级监督：**
- 上级交通运输主管部门对下级实施监督
- 定期开展安全生产检查
- 及时纠正违法执法行为

**专项监督：**
- 针对重点领域开展专项监督
- 针对重点时段开展专项监督
- 针对重大隐患开展专项监督

### 9.2 社会监督

**公众监督：**
- 公民、法人和其他组织有权对安全生产违法行为进行举报
- 对举报属实的，给予奖励
- 保护举报人的合法权益

**媒体监督：**
- 新闻媒体有权对安全生产违法行为进行舆论监督
- 交通运输主管部门应当自觉接受媒体监督

### 9.3 内部监督

**企业自查：**
- 建立安全生产自查制度
- 定期开展安全生产自查
- 及时发现和整改安全隐患

**员工监督：**
- 从业人员有权对本单位安全生产工作中存在的问题提出批评、检举、控告
- 从业人员有权拒绝违章指挥和强令冒险作业
