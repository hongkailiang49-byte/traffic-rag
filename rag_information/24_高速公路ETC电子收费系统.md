# 高速公路ETC电子收费系统

## 一、概述

ETC（Electronic Toll Collection，电子不停车收费系统）是利用DSRC（专用短程通信）技术，实现车辆在不停车的情况下自动完成通行费缴纳的收费系统。ETC系统通过安装在车辆挡风玻璃上的车载单元（OBU）与安装在收费车道上方的路侧单元（RSU）之间的微波通信，自动完成车辆识别、扣费和放行，大大提高了收费站的通行效率。

中国ETC系统主要遵循GB/T 20851系列国家标准，采用5.8GHz DSRC技术。截至2024年，中国ETC用户数量已超过2亿，高速公路ETC使用率超过90%，是全球规模最大的ETC系统。

## 二、技术原理

### 2.1 DSRC通信技术

ETC系统的核心通信技术是DSRC（Dedicated Short Range Communication，专用短程通信），工作频率为5.8GHz微波频段。DSRC采用主-从模式，RSU为主站，OBU为从站。通信参数如下：

| 参数 | 指标 |
|------|------|
| 工作频率 | 5.8GHz（5.795-5.805GHz） |
| 通信距离 | 3-30米 |
| 上行速率 | 500kbps |
| 下行速率 | 250kbps |
| 调制方式 | ASK/FSK |
| 工作模式 | 主-从模式（RSU主，OBU从） |

### 2.2 车辆识别原理

当装有OBU的车辆进入收费车道时，RSU通过5.8GHz微波信号唤醒OBU，建立双向通信链路。RSU读取OBU中存储的车辆身份信息（车型、车牌号等）和绑定的支付账户信息，完成身份认证后自动从账户中扣除通行费，随后控制栏杆机抬起放行。

### 2.3 加密与安全

ETC系统采用多层安全机制保障交易安全：

- **密钥体系**：采用全国统一的密钥管理系统，分为主密钥、密钥加密密钥和工作密钥三层
- **加密算法**：采用SM4国密算法、3DES、RSA等加密算法
- **双向认证**：RSU与OBU之间进行双向身份认证，防止伪造和重放攻击
- **防拆设计**：OBU采用防拆设计，拆卸即失效，防止OBU被盗用

## 三、系统架构

### 3.1 五层架构

中国ETC系统采用五层架构设计：

**第一层：部级中心/国家平台** — 负责全国联网清分结算，管理跨省交易数据，协调各省中心之间的资金清算。

**第二层：省级中心/结算平台** — 负责省内数据汇聚和拆分，管理本省ETC用户账户，处理省内交易的清分结算。

**第三层：路段/分中心** — 负责路段级管理，监控收费设备运行状态，处理异常交易。

**第四层：收费站/车道系统** — 负责收费站级控制，管理车道设备（RSU、栏杆机、车牌识别等），执行收费操作。

**第五层：车路通信设备层** — 包括RSU、OBU、车牌识别摄像头等终端设备，负责车辆识别和通信。

### 3.2 车道系统组成

收费车道系统由以下设备组成：

**RSU（路侧单元）**：安装在收费车道上方，通过5.8GHz微波与OBU通信，读取车辆信息和账户信息。

**OBU（车载单元）**：安装在车辆挡风玻璃上，存储车辆信息和支付账户信息，与RSU进行双向通信。

**车牌识别系统（ALPR）**：通过高清摄像头自动识别车辆车牌号，用于辅助验证和防作弊。

**车道控制器**：控制栏杆机、信号灯、费额显示器等设备的运行。

**称重设备**：用于货车的重量检测，防止超载。

**后台结算系统**：对接银行和第三方支付平台，完成通行费的清分结算。

### 3.3 ETC门架系统

2019年起，中国取消了高速公路省界收费站，采用ETC门架式自由流收费系统。ETC门架安装在高速公路主线上，车辆在正常行驶速度下即可完成扣费，无需在收费站停车。每个ETC门架配备RSU和车牌识别设备，用于记录车辆的行驶路径，实现精确计费。

## 四、工作流程

### 4.1 传统车道收费流程

1. **车辆驶入**：车辆进入ETC收费车道，车牌识别系统自动拍照
2. **RSU唤醒OBU**：RSU发出5.8GHz微波信号，唤醒车辆上的OBU
3. **身份认证**：RSU与OBU进行双向加密认证
4. **信息读取**：RSU读取OBU中的车辆信息和账户信息
5. **扣费计算**：系统根据车型、入口站、出口站等信息计算通行费
6. **执行扣费**：从绑定的ETC账户或银行卡中扣除费用
7. **抬杆放行**：栏杆机自动抬起，车辆通过
8. **数据上传**：交易记录上传至省级中心

### 4.2 门架式收费流程

1. **入口记录**：车辆通过入口门架时，系统记录入口信息（车牌、时间等）
2. **路径记录**：车辆通过沿途各门架时，系统记录行驶路径
3. **出口扣费**：车辆通过出口门架时，系统根据完整路径计算通行费并扣费
4. **清分结算**：交易数据上传至省级/部级中心进行清分结算

## 五、GB/T 20851标准体系

GB/T 20851是中国ETC系统的核心技术标准，包括以下部分：

| 标准编号 | 标准名称 | 主要内容 |
|----------|----------|----------|
| GB/T 20851.1 | 电子收费 专用短程通信 第1部分：物理层 | 5.8GHz物理层技术要求 |
| GB/T 20851.2 | 电子收费 专用短程通信 第2部分：数据链路层 | MAC层和LLC层协议 |
| GB/T 20851.3 | 电子收费 专用短程通信 第3部分：应用层 | 应用层协议和消息格式 |
| GB/T 20851.4 | 电子收费 专用短程通信 第4部分：设备应用 | OBU和RSU设备技术要求 |
| GB/T 20851.5 | 电子收费 专用短程通信 第5部分：物理层主要参数测试方法 | 物理层参数测试方法 |

## 六、技术发展趋势

### 6.1 ETC 2.0

ETC 2.0是在现有ETC系统基础上的升级演进，主要特点包括：支持更高速率的通信、支持更丰富的应用场景（如停车场收费、加油站支付等）、与V2X技术融合。

### 6.2 车牌付+ETC融合

基于车牌识别的无感支付正在与ETC系统融合，形成"ETC为主、车牌付为辅"的收费体系。对于未安装ETC的车辆，可以通过车牌识别+移动支付完成缴费。

### 6.3 北斗/GPS精确路径计费

结合北斗/GPS定位技术，可以实现基于精确行驶路径的计费，替代传统的"最短路径"或"最小费额"计费方式，使收费更加公平合理。

### 6.4 V2X融合

ETC正在向车路协同方向演进。未来的ETC终端可能集成V2X通信功能，成为车路协同系统的一部分，实现收费、通信、定位等多功能一体化。

### 6.5 多场景应用拓展

ETC技术正在从高速公路收费向城市道路收费、停车场收费、加油站支付、保险定价等多场景拓展，构建以ETC为核心的汽车服务生态。

## 七、国际比较

| 国家/地区 | 技术方案 | 工作频率 | 用户规模 |
|-----------|----------|----------|----------|
| 中国 | DSRC（GB/T 20851） | 5.8GHz | 2亿+ |
| 美国 | E-ZPass等 | 915MHz/5.8GHz | 约8000万 |
| 日本 | ETC/ETC2.0 | 5.8GHz | 约9000万 |
| 欧洲 | DSRC（CEN） | 5.8GHz | 各国不同 |

中国的ETC系统在用户规模、覆盖率和技术标准统一方面处于全球领先地位，为全球ETC技术发展提供了重要的参考经验。
