# 货运车辆超限超载治理

## 一、概述

货运车辆超限超载是我国道路交通管理领域长期存在的顽疾，严重危害道路交通安全、损坏公路基础设施、扰乱运输市场秩序。超限是指货运车辆的外廓尺寸、轴荷或总质量超过国家规定的限值；超载是指货运车辆实际装载的货物质量超过核定的载质量。两者既有联系又有区别，但在实际治理中通常一并处理。

近年来，我国持续加大超限超载治理力度，建立了较为完善的法律法规体系和技术标准体系。主要法律法规包括《公路法》《道路交通安全法》《公路安全保护条例》《超限运输车辆行驶公路管理规定》等。通过实施"一超四罚"制度、建设治超检测站点、推广不停车超限检测系统等措施，超限超载治理取得了显著成效，但治理形势依然严峻。

## 二、法律法规体系

### 2.1 《中华人民共和国公路法》

《公路法》是超限超载治理的基本法律依据，主要条款包括：

**第五十条**：超过公路、公路桥梁、公路隧道限载、限高、限宽、限长标准的车辆，不得在公路、公路桥梁或者公路上行驶；确需行驶的，应当经县级以上地方人民政府交通主管部门批准，并按要求采取有效的防护措施；运载不可解体的超限物品的，应当按照指定的时间、路线、时速行驶，并悬挂明显标志。

**第七十六条**：违反本法第五十条规定，车辆在公路上擅自超限行驶的，由交通主管部门责令停止违法行为，可以处三万元以下的罚款。

**第七十七条**：违反本法第四十六条的规定，造成公路路面损坏、污染或者影响公路畅通的，由交通主管部门责令停止违法行为，可以处五千元以下的罚款。

### 2.2 《中华人民共和国道路交通安全法》

《道路交通安全法》对超载行为作出了明确规定：

**第四十八条**：机动车载物应当符合核定的载质量，严禁超载；载物的长、宽、高不得违反装载要求，不得遗洒、飘散载运物。

**第九十二条**：货运机动车超过核定载质量的，处二百元以上五百元以下罚款；超过核定载质量百分之三十或者违反规定载客的，处五百元以上二千元以下罚款。

### 2.3 《公路安全保护条例》

《公路安全保护条例》（国务院令第593号）对超限超载治理作出了详细规定：

**第三十三条**：超过公路、公路桥梁、公路隧道限载、限高、限宽、限长标准的车辆，不得在公路、公路桥梁以及公路隧道行驶。

**第六十四条**：违反本条例的规定，在公路上行驶的车辆，车货总体的外廓尺寸、轴荷或者总质量超过公路、公路桥梁、公路隧道限定标准的，由公路管理机构责令改正，可以处3万元以下的罚款。

### 2.4 《超限运输车辆行驶公路管理规定》

《超限运输车辆行驶公路管理规定》（交通运输部令2016年第62号）是超限超载治理的核心部门规章，主要内容包括：

**超限运输车辆的定义：**
- 车货总高度从地面算起超过4米
- 车货总宽度超过2.55米
- 车货总长度超过18.1米
- 二轴货车车货总质量超过18吨
- 三轴货车车货总质量超过25吨
- 四轴货车车货总质量超过31吨
- 五轴货车车货总质量超过43吨
- 六轴及以上货车车货总质量超过49吨

**许可审批程序：**
- 运输不可解体物品需要超限运输的，承运人应当向公路管理机构申请办理超限运输许可
- 公路管理机构应当在法定期限内作出是否许可的决定
- 经批准的超限运输车辆应当按照指定的时间、路线、速度行驶

## 三、超限超载认定标准

### 3.1 车辆外廓尺寸限值

根据《汽车、挂车及汽车列车外廓尺寸、轴荷及质量限值》（GB 1589-2016）规定：

| 车辆类型 | 最大长度（米） | 最大宽度（米） | 最大高度（米） |
|---------|--------------|--------------|--------------|
| 二轴货车 | 12.0 | 2.55 | 4.0 |
| 三轴货车 | 12.0 | 2.55 | 4.0 |
| 半挂牵引车 | 12.0 | 2.55 | 4.0 |
| 挂车 | 13.75 | 2.55 | 4.0 |
| 半挂列车 | 16.5 | 2.55 | 4.0 |
| 中置轴列车 | 20.0 | 2.55 | 4.0 |
| 全挂列车 | 18.1 | 2.55 | 4.0 |

**特殊规定：**
- 集装箱车货总高度从地面算起不得超过4.2米
- 运输鲜活农产品的车辆高度从地面算起不得超过4.2米

### 3.2 车辆轴荷限值

| 轴型 | 最大轴荷（吨） |
|------|--------------|
| 单轴（每侧单轮胎） | 6.0 |
| 单轴（每侧双轮胎） | 10.0 |
| 双联轴（每侧单轮胎） | 10.0 |
| 双联轴（每侧双轮胎） | 18.0 |
| 三联轴（每侧单轮胎） | 12.0 |
| 三联轴（每侧双轮胎） | 22.0 |

### 3.3 车辆总质量限值

| 车辆类型 | 最大总质量（吨） |
|---------|----------------|
| 二轴货车 | 18.0 |
| 三轴货车 | 25.0 |
| 四轴货车 | 31.0 |
| 五轴货车 | 43.0 |
| 六轴及以上货车 | 49.0 |

**特殊规定：**
- 挂车及二轴货车的车货总质量还应当不超过行驶证标明的总质量
- 除驱动轴外，二轴组、三轴组以及半挂车和全挂车，每减少两个轮胎，其总质量限值减少4吨

## 四、治理措施

### 4.1 "一超四罚"制度

"一超四罚"是我国超限超载治理的核心制度，对违法超限超载行为实施多方联合惩戒：

**第一罚：罚驾驶人**
- 对超限超载车辆的驾驶人依法给予行政处罚
- 记分处理：超载30%以上记6分，超载未达30%记3分
- 罚款200元至2000元

**第二罚：罚车主**
- 对车辆所有人依法给予行政处罚
- 责令车辆所有人采取措施消除违法状态
- 拒不改正的，吊销车辆营运证

**第三罚：罚运输企业**
- 对运输企业依法给予行政处罚
- 责令运输企业加强安全管理
- 情节严重的，责令停业整顿

**第四罚：罚货源单位**
- 对为超限超载车辆配载的货源单位依法给予行政处罚
- 责令货源单位规范装载行为
- 情节严重的，责令停业整顿

### 4.2 治超检测站点建设

**站点类型：**
- 固定治超检测站：设置在国省干线公路上，配备完善的检测设备
- 临时治超检测站：根据治理需要临时设置
- 不停车超限检测系统：利用技术手段实现车辆不停车检测

**站点功能：**
- 车辆称重检测
- 车辆外廓尺寸检测
- 车辆信息查询
- 违法行为处理
- 超限车辆卸载

**站点布局原则：**
- 在主要货物运输通道上设置
- 在重要桥梁、隧道入口处设置
- 在省界入口处设置
- 在大型工矿企业周边设置

### 4.3 不停车超限检测系统

不停车超限检测系统是超限超载治理的重要技术手段，主要包括：

**系统组成：**
- 高速称重设备：实现车辆不停车称重
- 车辆外廓尺寸检测设备：自动检测车辆外廓尺寸
- 车牌识别系统：自动识别车辆号牌
- 视频监控系统：记录车辆通行信息
- 数据处理系统：自动处理检测数据

**技术特点：**
- 检测速度快：车辆不停车即可完成检测
- 检测精度高：称重误差不超过±5%
- 自动化程度高：减少人工干预
- 覆盖范围广：可实现全天候检测

**应用效果：**
- 提高检测效率
- 减少交通拥堵
- 降低执法成本
- 提高治理效果

### 4.4 非现场执法

非现场执法是超限超载治理的重要方式：

**执法依据：**
- 通过不停车超限检测系统采集的证据
- 通过视频监控系统采集的证据
- 通过电子称重设备采集的证据

**执法程序：**
- 数据采集：自动采集车辆超限超载数据
- 数据审核：对采集的数据进行审核
- 告知当事人：通过邮寄、短信等方式告知当事人
- 当事人处理：当事人在规定期限内接受处理
- 强制执行：逾期不处理的，申请人民法院强制执行

**证据要求：**
- 检测设备应当经过计量检定
- 检测数据应当完整、准确
- 视频资料应当清晰、完整
- 检测过程应当有记录

## 五、源头治理

### 5.1 货源单位管理

**货源单位责任：**
- 建立货物装载管理制度
- 配备称重设备
- 对装载的货物进行称重
- 不得为超限超载车辆配载

**监管措施：**
- 对货源单位进行定期检查
- 对违规货源单位实施处罚
- 建立货源单位信用档案
- 实施货源单位黑名单制度

### 5.2 车辆生产改装管理

**车辆生产管理：**
- 车辆生产企业应当按照国家标准生产车辆
- 车辆生产企业不得生产超限超载车辆
- 车辆生产企业应当在车辆出厂时标注车辆技术参数

**车辆改装管理：**
- 禁止非法改装车辆
- 车辆改装应当符合国家标准
- 车辆改装应当经相关部门批准
- 车辆改装后应当重新进行检验

### 5.3 运输企业管理

**企业主体责任：**
- 建立安全生产管理制度
- 加强驾驶人安全教育
- 建立车辆技术档案
- 不得指使、强令驾驶人超限超载运输

**监管措施：**
- 对运输企业进行安全评估
- 对违规运输企业实施处罚
- 建立运输企业信用档案
- 实施运输企业黑名单制度

## 六、联合执法机制

### 6.1 部门联合执法

超限超载治理涉及多个部门，需要建立联合执法机制：

**参与部门：**
- 交通运输部门：负责公路超限检测和处罚
- 公安机关：负责道路交通安全管理
- 工业和信息化部门：负责车辆生产管理
- 市场监管部门：负责车辆改装管理
- 应急管理部门：负责安全生产监管

**协作机制：**
- 建立联合执法工作机制
- 定期开展联合执法行动
- 共享执法信息
- 协调处理重大案件

### 6.2 区域联合执法

超限超载治理需要跨区域协作：

**省际联合：**
- 建立省际联合执法机制
- 开展省际联合执法行动
- 共享省际治超信息
- 协调处理跨省案件

**市县联合：**
- 建立市县联合执法机制
- 开展市县联合执法行动
- 共享市县治超信息
- 协调处理跨市县案件

### 6.3 信息共享机制

**数据共享：**
- 建立治超信息管理系统
- 实现各部门数据共享
- 建立车辆超限超载数据库
- 建立违法当事人数据库

**信用管理：**
- 建立超限超载信用档案
- 实施信用联合惩戒
- 将严重违法当事人列入黑名单
- 定期公布违法信息

## 七、法律责任

### 7.1 行政处罚

**对驾驶人的处罚：**
- 超过核定载质量30%以上或者违反规定载客的，处500元以上2000元以下罚款
- 超过核定载质量未达30%的，处200元以上500元以下罚款
- 超限超载的，记3分至6分

**对车辆所有人的处罚：**
- 货运机动车超过核定载质量的，处200元以上500元以下罚款
- 超过核定载质量30%或者违反规定载客的，处500元以上2000元以下罚款

**对运输企业的处罚：**
- 运输单位的车辆超限超载，经处罚不改的，对直接负责的主管人员处2000元以上5000元以下罚款

**对货源单位的处罚：**
- 为超限超载车辆配载的，处1万元以上3万元以下罚款

### 7.2 强制措施

**扣留车辆：**
- 对超限超载车辆可以扣留至违法状态消除
- 超限超载车辆应当卸载后方可放行

**吊销证件：**
- 对严重超限超载的车辆，可以吊销营运证
- 对多次超限超载的驾驶人，可以吊销从业资格证

### 7.3 刑事责任

**以危险方法危害公共安全罪：**
- 因超限超载导致重大交通事故的，可能构成以危险方法危害公共安全罪
- 处三年以上十年以下有期徒刑

**重大责任事故罪：**
- 因超限超载导致重大事故的，可能构成重大责任事故罪
- 处三年以下有期徒刑或者拘役

## 八、技术标准体系

### 8.1 车辆技术标准

| 标准编号 | 标准名称 | 主要内容 |
|---------|---------|---------|
| GB 1589-2016 | 汽车、挂车及汽车列车外廓尺寸、轴荷及质量限值 | 车辆尺寸和质量限值 |
| GB 7258-2017 | 机动车运行安全技术条件 | 车辆安全技术要求 |
| GB/T 26774 | 车辆外廓尺寸测量方法 | 车辆尺寸测量方法 |
| JJG 907 | 动态公路车辆自动衡器 | 称重设备检定规程 |

### 8.2 检测设备标准

**高速称重设备：**
- 称重误差：不超过±5%
- 检测速度：5-200km/h
- 轴数识别准确率：不低于99%

**外廓尺寸检测设备：**
- 长度测量误差：不超过±50mm
- 宽度测量误差：不超过±30mm
- 高度测量误差：不超过±30mm

**车牌识别系统：**
- 识别准确率：不低于99%
- 识别速度：不超过200ms
- 适用环境：白天、夜间、雨雪天气

## 九、治理成效与展望

### 9.1 治理成效

近年来，我国超限超载治理取得了显著成效：

- 超限超载率显著下降
- 公路基础设施损坏明显减少
- 道路交通事故明显下降
- 运输市场秩序明显改善

### 9.2 存在问题

超限超载治理仍面临一些挑战：

- 部分地区治理力度不够
- 源头治理有待加强
- 非现场执法推广不够
- 信用惩戒机制有待完善

### 9.3 未来展望

**技术发展：**
- 推广智能化治超检测系统
- 建设全国统一的治超信息平台
- 推广非现场执法
- 加强大数据分析应用

**制度完善：**
- 完善法律法规体系
- 健全联合执法机制
- 完善信用惩戒机制
- 加强源头治理
