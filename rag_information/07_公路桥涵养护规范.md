# 公路桥涵养护规范

## 一、规范概述

《公路桥涵养护规范》（JTG 5120-2021）是中华人民共和国交通运输部发布的公路养护行业标准，于2021年发布实施，替代原JTG H11-2004版本。该规范是我国公路桥涵养护管理的基本技术依据，适用于各级公路桥涵的养护管理工作。

该规范的制定目的是规范公路桥涵养护技术工作，保障桥涵安全运营，延长桥涵使用寿命，为社会提供安全、畅通的公路交通服务。

## 二、桥涵养护基本原则

### （一）养护方针

桥涵养护工作应遵循"**预防为主、防治结合**"的方针，坚持"**科学养护、及时养护、全面养护**"的原则。

### （二）养护目标

- 保持桥涵结构完好和安全运营
- 及时发现和处治病害
- 保障桥涵通行能力和承载能力
- 延长桥涵使用寿命

### （三）养护分类

桥涵养护按工程性质和规模分为四类：

| 养护类型 | 工程内容 | 特点 |
|---------|---------|------|
| 保养与小修 | 日常保养、小型修补 | 经常性、预防性 |
| 中修工程 | 局部损坏修复 | 工程量中等 |
| 大修工程 | 较大范围损坏修复 | 工程量大 |
| 改建工程 | 不满足使用要求的改造 | 工程量很大 |

## 三、桥涵检查制度

### （一）检查分类

桥涵检查分为经常检查、定期检查和特殊检查三类。

**1. 经常检查**

| 检查项目 | 要求 |
|---------|------|
| 检查频率 | 每月至少一次 |
| 检查内容 | 桥面设施、上下部结构外观 |
| 检查方法 | 目测检查为主 |
| 检查人员 | 养护技术人员 |
| 记录要求 | 填写检查记录表 |

**2. 定期检查**

| 检查项目 | 要求 |
|---------|------|
| 检查频率 | 一般桥梁每三年一次，重要桥梁每年一次 |
| 检查内容 | 全面检查桥涵技术状况 |
| 检查方法 | 专业检测设备 |
| 检查人员 | 专业检测机构 |
| 记录要求 | 编写检查报告 |

**3. 特殊检查**

| 检查项目 | 要求 |
|---------|------|
| 检查时机 | 遭受重大灾害、超重车辆通行后 |
| 检查内容 | 专项检查 |
| 检查方法 | 专业检测机构 |
| 检查人员 | 专业检测机构 |
| 记录要求 | 编写专项检查报告 |

### （二）检查内容

**1. 桥面系检查**

| 检查项目 | 检查内容 |
|---------|---------|
| 桥面铺装 | 裂缝、坑槽、车辙、拥包 |
| 伸缩缝 | 损坏、堵塞、漏水 |
| 排水系统 | 排水畅通性、损坏情况 |
| 人行道 | 损坏、栏杆完好性 |
| 标志标线 | 完好性、清晰度 |

**2. 上部结构检查**

| 检查项目 | 检查内容 |
|---------|---------|
| 主梁 | 裂缝、变形、混凝土剥落 |
| 横隔板 | 裂缝、连接完好性 |
| 桥面板 | 裂缝、损坏 |
| 预应力构件 | 锚固端状况、裂缝 |

**3. 下部结构检查**

| 检查项目 | 检查内容 |
|---------|---------|
| 桥墩 | 裂缝、冲刷、倾斜 |
| 桥台 | 裂缝、位移、沉降 |
| 基础 | 冲刷、暴露、损坏 |
| 支座 | 位移、损坏、老化 |

**4. 附属设施检查**

| 检查项目 | 检查内容 |
|---------|---------|
| 锥坡护坡 | 损坏、冲刷 |
| 导流堤 | 损坏、冲刷 |
| 河床防护 | 冲刷、损坏 |
| 照明设施 | 完好性 |

## 四、桥涵技术状况评定

### （一）评定方法

桥涵技术状况评定采用**技术状况指数（BCI）**方法，根据检查结果对桥涵各部件进行评分，综合评定桥涵技术状况等级。

### （二）评定等级

桥涵技术状况分为五类：

| 评定等级 | BCI值范围 | 技术状况描述 | 养护对策 |
|---------|----------|------------|---------|
| 1类 | ≥90 | 完好状态 | 正常保养 |
| 2类 | 80～89 | 良好状态 | 保养、小修 |
| 3类 | 70～79 | 较差状态 | 中修 |
| 4类 | 60～69 | 差的状态 | 大修或改造 |
| 5类 | <60 | 危险状态 | 改建或重建 |

### （三）各部件权重

| 部件名称 | 权重 |
|---------|------|
| 上部结构 | 0.40 |
| 下部结构 | 0.40 |
| 桥面系 | 0.20 |

### （四）评定流程

1. 现场检查，收集数据
2. 各部件评分
3. 计算BCI值
4. 确定技术状况等级
5. 提出养护对策

## 六、桥涵附属设施养护

### （一）桥面铺装养护

**1. 沥青混凝土桥面**

| 病害类型 | 处治方法 |
|---------|---------|
| 裂缝 | 灌缝、贴缝 |
| 坑槽 | 切割修补 |
| 车辙 | 铣刨重铺 |
| 拥包 | 铣刨处理 |

**2. 水泥混凝土桥面**

| 病害类型 | 处治方法 |
|---------|---------|
| 裂缝 | 灌缝修补 |
| 破碎 | 局部更换 |
| 磨损 | 加铺处理 |

### （二）伸缩缝养护

| 伸缩缝类型 | 常见病害 | 养护措施 |
|-----------|---------|---------|
| 模数式伸缩缝 | 橡胶条损坏、锚固区损坏 | 更换橡胶条、修补锚固区 |
| 梳齿板伸缩缝 | 梳齿板损坏、锚固区损坏 | 更换梳齿板、修补锚固区 |
| 弹塑体伸缩缝 | 弹塑体脱落、损坏 | 重做伸缩缝 |

### （三）支座养护

| 支座类型 | 常见病害 | 养护措施 |
|---------|---------|---------|
| 板式橡胶支座 | 老化、开裂、脱空 | 更换支座 |
| 盆式橡胶支座 | 橡胶老化、盆环损坏 | 更换支座 |
| 球型支座 | 转动不灵活、锈蚀 | 维修、更换 |

### （四）排水设施养护

- 定期清理排水管道
- 修复损坏的排水设施
- 保持排水畅通
- 防止桥面积水

## 七、超重车辆过桥管理

### （一）超重车辆定义

- 车货总质量超过桥梁设计荷载标准
- 轴载质量超过规定限值

### （二）过桥审批程序

1. 提出申请
2. 技术评估
3. 审批同意
4. 实施监护

### （三）过桥技术要求

- 限速通行
- 居中行驶
- 禁止制动
- 专人监护

## 八、桥涵灾害防治与应急处置

### （一）洪水灾害防治

**1. 防洪检查**
- 汛前检查桥涵排水设施
- 检查基础冲刷情况
- 检查河床变化

**2. 防洪措施**
- 清理河道淤积
- 加固基础防护
- 设置防洪设施

### （二）地震灾害防治

**1. 抗震检查**
- 检查桥涵结构抗震性能
- 评估地震风险

**2. 抗震措施**
- 加固桥涵结构
- 设置防落梁装置
- 安装减隔震装置

### （三）船舶碰撞防治

**1. 防撞设施**
- 设置防撞墩
- 设置警示标志

**2. 碰撞后处置**
- 评估结构损伤
- 及时修复加固

### （四）应急处置

**1. 应急预案**
- 制定桥涵应急预案
- 储备应急物资
- 组织应急演练

**2. 应急响应**
- 及时报告险情
- 启动应急预案
- 组织抢修保通

## 九、桥涵档案管理

### （一）档案内容

- 桥涵设计文件
- 施工文件
- 竣工文件
- 检查记录
- 维修记录
- 技术评定报告

### （二）档案管理要求

- 建立桥涵档案数据库
- 及时更新档案信息
- 做好档案保管工作
- 实现信息化管理

## 十、桥涵养护管理

### （一）养护计划管理

- 编制年度养护计划
- 合理安排养护资金
- 优化养护方案

### （二）养护质量管理

- 建立养护质量标准
- 实施养护工程验收
- 开展养护质量考核

### （三）养护人员要求

- 具备专业知识和技能
- 定期培训和考核
- 持证上岗
