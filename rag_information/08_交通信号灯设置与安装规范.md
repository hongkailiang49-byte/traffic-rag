# 交通信号灯设置与安装规范

## 一、规范概述

《道路交通信号灯设置与安装规范》（GB 14886-2016）是中华人民共和国国家标准，于2016年发布实施，替代原GB 14886-2006版本。该规范规定了道路交通信号灯的设置条件、安装要求和技术规范，适用于城市道路、公路交叉口和路段的交通信号灯设置与安装。

该规范的制定目的是规范道路交通信号灯的设置和安装，保障交通安全和通行效率，为交通管理部门提供技术依据。

## 二、信号灯类型与功能

### （一）按用途分类

| 信号灯类型 | 功能说明 | 适用场景 |
|-----------|---------|---------|
| 机动车信号灯 | 控制机动车通行 | 交叉口、路段 |
| 非机动车信号灯 | 控制非机动车通行 | 交叉口、路段 |
| 人行横道信号灯 | 控制行人过街 | 人行横道 |
| 方向指示信号灯 | 指示转向方向 | 交叉口 |
| 车道信号灯 | 控制车道使用 | 多车道道路 |
| 闪光警告信号灯 | 发出警告信号 | 危险路段 |
| 道口信号灯 | 控制铁路道口 | 铁路道口 |

### （二）按显示方式分类

| 信号灯类型 | 显示方式 | 说明 |
|-----------|---------|------|
| 圆形信号灯 | 红、黄、绿圆形 | 基本信号灯 |
| 箭头信号灯 | 红、黄、绿箭头 | 方向指示 |
| 人行信号灯 | 红、绿人形 | 行人过街 |
| 数字信号灯 | 数字倒计时 | 倒计时显示 |

### （三）信号灯组合方式

**1. 机动车信号灯组合**

| 组合方式 | 适用场景 | 显示方式 |
|---------|---------|---------|
| 竖向安装 | 一般交叉口 | 从上到下：红、黄、绿 |
| 横向安装 | 特殊交叉口 | 从左到右：红、黄、绿 |

**2. 方向指示信号灯组合**

| 组合方式 | 说明 |
|---------|------|
| 左转箭头灯 | 控制左转车辆 |
| 右转箭头灯 | 控制右转车辆 |
| 直行箭头灯 | 控制直行车辆 |
| 左转+直行组合 | 控制左转和直行 |

## 三、信号灯设置条件

### （一）交叉口信号灯设置条件

**1. 交通流量条件**

满足以下条件之一时，应设置信号灯：

| 条件 | 标准 |
|------|------|
| 主要道路流量 | 高峰小时流量达到1500pcu/h |
| 次要道路流量 | 高峰小时流量达到750pcu/h |
| 交叉口总流量 | 高峰小时流量达到2000pcu/h |
| 行人流量 | 高峰小时行人流量达到500人次/h |

**2. 事故条件**

满足以下条件时，应设置信号灯：

| 条件 | 标准 |
|------|------|
| 年事故次数 | 5年内发生5次以上交通事故 |
| 伤亡事故 | 5年内发生1次以上伤亡事故 |

**3. 综合条件**

当交通流量和事故条件均未达到标准，但满足以下条件时，可设置信号灯：

- 学校、医院、政府机关等特殊单位出入口
- 大型商业设施出入口
- 公交枢纽出入口
- 其他需要设置信号灯的地点

### （二）路段信号灯设置条件

**1. 人行横道信号灯**

满足以下条件时，应设置人行横道信号灯：

| 条件 | 标准 |
|------|------|
| 道路宽度 | 四车道以上 |
| 车流量 | 高峰小时流量达到1000pcu/h |
| 行人流量 | 高峰小时行人流量达到200人次/h |
| 事故条件 | 5年内发生2次以上行人事故 |

**2. 行人请求式信号灯**

适用于行人流量较小的路段：

- 行人按下请求按钮
- 系统根据交通状况响应
- 可减少对车辆的干扰

### （三）特殊场景信号灯设置

**1. 学校区域**

- 学校出入口应设置信号灯
- 应设置行人过街信号灯
- 应设置限速标志

**2. 医院区域**

- 医院出入口宜设置信号灯
- 应考虑无障碍设施

**3. 铁路道口**

- 应设置道口信号灯
- 应与栏木系统联动
- 应设置闪光警告信号灯

**4. 公交专用道**

- 公交专用道入口宜设置车道信号灯
- 应设置公交优先信号

## 四、信号灯安装要求

### （一）安装位置

**1. 交叉口信号灯安装位置**

| 安装方式 | 适用条件 | 安装位置 |
|---------|---------|---------|
| 悬臂式 | 多车道道路 | 安装在进口道右侧或上方 |
| 门架式 | 高速公路、快速路 | 安装在道路上方 |
| 柱式 | 支路、小区道路 | 安装在进口道右侧 |
| 附着式 | 有路灯杆的道路 | 附着在路灯杆上 |

**2. 人行横道信号灯安装位置**

| 安装方式 | 安装位置 |
|---------|---------|
| 立柱式 | 安装在人行横道两端 |
| 附着式 | 附着在路灯杆或信号灯杆上 |

### （二）安装高度

| 信号灯类型 | 安装高度（m） | 说明 |
|-----------|--------------|------|
| 悬臂式机动车信号灯 | 5.5～7.0 | 距路面高度 |
| 门架式机动车信号灯 | 5.5～7.0 | 距路面高度 |
| 柱式机动车信号灯 | 3.0～5.0 | 距路面高度 |
| 人行横道信号灯 | 2.0～3.0 | 距路面高度 |

### （三）安装角度

| 信号灯类型 | 安装角度要求 |
|-----------|------------|
| 机动车信号灯 | 与道路轴线成0°～15°角 |
| 方向指示信号灯 | 与对应车道方向一致 |
| 人行横道信号灯 | 面向行人方向 |

### （四）可视性要求

**1. 可视距离**

| 信号灯类型 | 最小可视距离（m） |
|-----------|-----------------|
| 机动车信号灯 | 150 |
| 方向指示信号灯 | 150 |
| 人行横道信号灯 | 100 |

**2. 可视角度**

| 安装方式 | 可视角度要求 |
|---------|------------|
| 悬臂式 | 进口道中心线两侧各15° |
| 门架式 | 进口道中心线两侧各15° |
| 柱式 | 进口道中心线两侧各10° |

## 六、信号配时设计

### （一）信号相位设计

**1. 相位数选择**

| 交叉口类型 | 推荐相位数 | 说明 |
|-----------|-----------|------|
| 简单交叉口 | 2相位 | 东西、南北交替 |
| 一般交叉口 | 3～4相位 | 增加左转相位 |
| 复杂交叉口 | 4～6相位 | 多方向独立控制 |

**2. 相位顺序设计**

| 相位顺序 | 适用场景 | 说明 |
|---------|---------|------|
| 先直行后左转 | 一般交叉口 | 常用方案 |
| 先左转后直转 | 左转流量大 | 提高安全性 |
| 全红清空 | 所有场景 | 确保安全 |

### （二）信号周期设计

**1. 周期时长确定**

| 交通状况 | 周期时长（s） | 说明 |
|---------|--------------|------|
| 轻度交通 | 60～90 | 交通量小 |
| 中度交通 | 90～120 | 交通量中等 |
| 重度交通 | 120～180 | 交通量大 |

**2. 周期时长计算**

最短周期时长计算公式：
```
Cmin = (L + ΣLi) / (1 - ΣYi)
```
其中：
- Cmin：最短周期时长（s）
- L：总损失时间（s）
- Li：各相位损失时间（s）
- Yi：各相位流量比

### （三）绿灯时间设计

**1. 最短绿灯时间**

| 车道类型 | 最短绿灯时间（s） |
|---------|-----------------|
| 机动车道 | 15 |
| 非机动车道 | 12 |
| 人行横道 | 根据过街距离确定 |

**2. 行人过街时间计算**

行人过街最短绿灯时间计算公式：
```
Gp = 7 + Lp/Vp
```
其中：
- Gp：行人绿灯时间（s）
- Lp：人行横道长度（m）
- Vp：行人步行速度（取1.0m/s）

### （四）黄灯与全红时间

| 参数 | 取值范围 | 说明 |
|------|---------|------|
| 黄灯时间 | 3～5s | 用于清空交叉口 |
| 全红时间 | 2～3s | 确保安全清空 |

## 七、信号灯配套设施

### （一）信号控制机

**1. 功能要求**

| 功能 | 说明 |
|------|------|
| 定时控制 | 按预设配时运行 |
| 感应控制 | 根据检测器信号调整 |
| 协调控制 | 多交叉口绿波协调 |
| 手动控制 | 人工干预 |
| 黄闪控制 | 故障时黄闪运行 |

**2. 技术要求**

| 技术参数 | 要求 |
|---------|------|
| 计时精度 | ±1s/24h |
| 相位数 | 不少于16相位 |
| 检测器接口 | 不少于32路 |
| 通信接口 | 支持多种通信方式 |

### （二）交通检测器

**1. 检测器类型**

| 检测器类型 | 工作原理 | 适用场景 |
|-----------|---------|---------|
| 地磁检测器 | 检测车辆磁场 | 车道检测 |
| 视频检测器 | 图像分析 | 多车道检测 |
| 微波检测器 | 微波反射 | 车辆检测 |
| 红外检测器 | 红外反射 | 行人检测 |

**2. 安装要求**

| 安装参数 | 要求 |
|---------|------|
| 安装位置 | 停车线后1～2m |
| 安装深度 | 地下10～15cm（地磁） |
| 安装高度 | 5～8m（视频） |

### （三）通信系统

**1. 通信方式**

| 通信方式 | 适用场景 | 特点 |
|---------|---------|------|
| 光纤通信 | 主干网络 | 带宽大、稳定 |
| 无线通信 | 分散节点 | 灵活、成本低 |
| 专有通信 | 特殊需求 | 可靠性高 |

**2. 通信协议**

- 应符合国家标准
- 应支持远程监控
- 应支持数据上传

## 八、信号灯维护管理

### （一）日常维护

| 维护项目 | 维护频率 | 维护内容 |
|---------|---------|---------|
| 外观检查 | 每日 | 检查信号灯完好性 |
| 功能检查 | 每周 | 检查信号灯功能 |
| 电气检查 | 每月 | 检查电气参数 |
| 全面检查 | 每年 | 全面检测维护 |

### （二）故障处理

**1. 常见故障类型**

| 故障类型 | 表现 | 处理措施 |
|---------|------|---------|
| 灯珠损坏 | 亮度下降或不亮 | 更换灯珠 |
| 控制机故障 | 信号异常 | 检修或更换 |
| 通信故障 | 数据传输中断 | 检查通信线路 |
| 电源故障 | 信号灯不亮 | 检查电源 |

**2. 应急处理**

- 设置临时交通标志
- 安排人员指挥交通
- 及时抢修恢复

### （三）备品备件管理

- 储备常用备品备件
- 建立备件台账
- 定期检查补充
