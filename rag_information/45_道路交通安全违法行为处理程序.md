# 道路交通安全违法行为处理程序规定

## 一、概述

《道路交通安全违法行为处理程序规定》（公安部令第105号）是规范公安机关交通管理部门处理道路交通安全违法行为程序的部门规章。该规定最初于2004年发布实施，2008年进行修订（公安部令第105号），2020年再次修订（公安部令第157号），自2020年5月1日起施行。

该规定旨在规范道路交通安全违法行为处理程序，保障公安机关交通管理部门依法实施行政处罚，保护当事人的合法权益，维护道路交通秩序。规定共八章，包括总则、管辖、调查取证、行政强制措施适用、行政处罚、非现场执法、其他规定和附则。

## 二、管辖制度

### 2.1 地域管辖

道路交通安全违法行为的管辖原则：

**违法行为发生地管辖：**
- 交通技术监控设备记录的违法行为，由违法行为发生地或者机动车登记地的公安机关交通管理部门管辖
- 现场查处的违法行为，由违法行为发生地的公安机关交通管理部门管辖

**机动车登记地管辖：**
- 机动车登记地的公安机关交通管理部门可以管辖该机动车的违法行为
- 当事人可以选择在违法行为发生地或者机动车登记地接受处理

### 2.2 级别管辖

**县级公安机关交通管理部门：**
- 负责处理本行政区域内的交通违法行为
- 负责实施行政处罚
- 负责采取行政强制措施

**设区的市级公安机关交通管理部门：**
- 负责处理本行政区域内的重大交通违法行为
- 负责指导下级公安机关交通管理部门的工作
- 负责协调跨区域的交通违法行为处理

### 2.3 管辖争议

**管辖争议的处理：**
- 两个以上公安机关交通管理部门都有管辖权的，由最先立案的管辖
- 对管辖有争议的，由共同的上一级公安机关交通管理部门指定管辖
- 上级公安机关交通管理部门可以直接处理下级管辖的案件

## 三、调查取证

### 3.1 调查程序

**调查要求：**
- 全面、及时、合法收集证据
- 依法告知当事人享有的权利
- 听取当事人的陈述和申辩
- 制作调查笔录

**调查方式：**
- 询问当事人、证人
- 勘验、检查
- 鉴定、检验
- 调取视听资料、电子数据

### 3.2 证据种类

**法定证据种类：**
- 书证：包括机动车驾驶证、行驶证等
- 物证：包括车辆、痕迹等
- 视听资料：包括监控视频、执法记录仪视频等
- 电子数据：包括交通技术监控设备记录的数据
- 当事人陈述
- 证人证言
- 鉴定意见
- 勘验笔录、现场笔录

### 3.3 交通技术监控设备记录

**设备要求：**
- 交通技术监控设备应当符合国家标准
- 交通技术监控设备应当经过计量检定
- 交通技术监控设备应当定期维护保养
- 交通技术监控设备应当设置在规定地点

**记录要求：**
- 记录应当清晰、完整
- 记录应当能够反映违法行为的时间、地点、车辆信息等
- 记录应当经过审核
- 记录应当保存不少于2年

**告知程序：**
- 公安机关交通管理部门应当在违法行为发生后10个工作日内告知当事人
- 告知方式包括邮寄、短信、电子邮件等
- 告知内容包括违法行为时间、地点、事实、处罚依据等
- 当事人有权进行陈述和申辩

## 四、行政强制措施

### 4.1 适用情形

公安机关交通管理部门可以采取的行政强制措施包括：

**扣留车辆：**
- 未悬挂机动车号牌的
- 未放置检验合格标志的
- 未放置保险标志的
- 未随车携带机动车驾驶证的
- 有被盗抢嫌疑的
- 有拼装或者达到报废标准嫌疑的

**扣留驾驶证：**
- 饮酒后驾驶机动车的
- 将机动车交由未取得机动车驾驶证的人驾驶的
- 机动车行驶超过规定时速50%的
- 驾驶拼装或者已达报废标准的机动车的
- 在一个记分周期内累积记分达到12分的

**拖移机动车：**
- 违反机动车停放、临时停车规定，驾驶人不在现场或者虽在现场但拒绝立即驶离的
- 妨碍其他车辆、行人通行的

**收缴非法装置：**
- 非法安装警报器、标志灯具的
- 非法安装或者使用卫星定位装置的
- 擅自改变机动车外形和已登记的有关技术数据的

**检验体内酒精、毒品含量：**
- 对有饮酒后驾驶机动车嫌疑的驾驶人进行呼气酒精测试
- 对有醉酒驾驶机动车嫌疑的驾驶人进行血液酒精含量检验
- 对有吸毒嫌疑的驾驶人进行毒品含量检验

### 4.2 实施程序

**扣留车辆程序：**
1. 出示执法证件
2. 告知当事人扣留的理由和依据
3. 制作行政强制措施凭证
4. 当事人签名或者盖章
5. 将车辆移至指定地点

**扣留驾驶证程序：**
1. 出示执法证件
2. 告知当事人扣留的理由和依据
3. 制作行政强制措施凭证
4. 当事人签名或者盖章

**拖移机动车程序：**
1. 出示执法证件
2. 告知当事人拖移的理由和依据
3. 制作行政强制措施凭证
4. 将车辆拖移至指定地点
5. 不得向当事人收取拖车费用

### 4.3 期限规定

**扣留期限：**
- 扣留车辆的，应当在24小时内将车辆移至指定地点
- 扣留驾驶证的，应当在24小时内将驾驶证移至指定地点
- 扣留期限一般不超过30日
- 情况复杂的，经批准可以延长30日

**处理期限：**
- 公安机关交通管理部门应当在扣留车辆后48小时内作出处理决定
- 需要检验、鉴定的，应当在检验、鉴定结论确定之日起5日内作出处理决定
- 处理完毕后，应当及时退还车辆或者驾驶证

## 五、行政处罚

### 5.1 处罚种类

**法定处罚种类：**
- 警告
- 罚款
- 暂扣机动车驾驶证
- 吊销机动车驾驶证
- 行政拘留

**处罚标准：**

| 违法行为 | 处罚标准 |
|---------|---------|
| 饮酒后驾驶机动车 | 暂扣6个月驾驶证，罚款1000-2000元 |
| 醉酒驾驶机动车 | 吊销驾驶证，5年内不得重新取得 |
| 超速50%以上 | 罚款200-2000元，可以吊销驾驶证 |
| 违反交通信号灯 | 罚款200元，记6分 |
| 不按规定让行 | 罚款200元，记3分 |
| 违法停车 | 罚款20-200元 |

### 5.2 简易程序

**适用条件：**
- 对个人处以200元以下罚款的
- 对单位处以1000元以下罚款的
- 警告处罚的

**程序要求：**
1. 口头告知当事人违法行为事实、处罚理由和依据
2. 听取当事人的陈述和申辩
3. 填写行政处罚决定书
4. 当场交付当事人
5. 当事人签名或者盖章

### 5.3 一般程序

**适用条件：**
- 不适用简易程序的
- 当事人对简易程序处理有异议的
- 需要进一步调查的

**程序要求：**
1. 立案
2. 调查取证
3. 告知当事人拟作出处罚的事实、理由和依据
4. 听取当事人的陈述和申辩
5. 制作行政处罚决定书
6. 送达当事人
7. 执行

### 5.4 听证程序

**适用条件：**
- 对个人处以2000元以上罚款的
- 对单位处以10000元以上罚款的
- 吊销机动车驾驶证的
- 当事人要求听证的

**程序要求：**
1. 当事人在收到听证告知书之日起3日内提出听证申请
2. 公安机关交通管理部门在听证的7日前通知当事人
3. 举行听证会
4. 听证结束后，制作听证笔录
5. 根据听证结果作出处罚决定

## 六、非现场执法

### 6.1 非现场执法的定义

非现场执法是指公安机关交通管理部门通过交通技术监控设备记录的违法行为，依法对当事人实施行政处罚的执法方式。

### 6.2 处理方式

**网上处理：**
- 当事人可以通过互联网交通安全综合服务管理平台处理非现场交通违法
- 当事人可以通过"交管12123"手机APP处理非现场交通违法
- 网上处理适用于罚款200元以下且记分不满12分的违法行为

**窗口处理：**
- 当事人可以到公安机关交通管理部门窗口处理非现场交通违法
- 窗口处理适用于所有非现场交通违法
- 需要携带机动车驾驶证、行驶证等证件

**跨省异地处理：**
- 当事人可以在违法行为发生地或者机动车登记地以外的省份处理非现场交通违法
- 跨省异地处理适用于所有非现场交通违法
- 当事人可以选择在网上或者窗口处理

### 6.3 告知程序

**告知时限：**
- 公安机关交通管理部门应当在违法行为发生后10个工作日内告知当事人
- 通过邮寄方式告知的，以挂号信寄出之日起计算
- 通过短信、电子邮件方式告知的，以发送成功之日起计算

**告知内容：**
- 违法行为的时间、地点
- 违法行为的事实
- 处罚的依据
- 当事人享有的权利

**告知方式：**
- 邮寄告知：以挂号信方式邮寄至当事人登记的地址
- 短信告知：以短信方式发送至当事人登记的手机号码
- 电子邮件告知：以电子邮件方式发送至当事人登记的电子邮箱
- 公告告知：无法通过上述方式告知的，公告告知

### 6.4 证据要求

**证据标准：**
- 交通技术监控设备记录应当清晰、完整
- 能够反映违法行为的时间、地点、车辆信息
- 能够反映违法行为的事实
- 能够识别车辆号牌和驾驶人

**证据审核：**
- 公安机关交通管理部门应当对非现场执法证据进行审核
- 审核内容包括设备状态、记录清晰度、违法行为认定等
- 审核通过后方可作为处罚依据
- 审核不通过的，应当重新记录或者不予处罚

## 七、记分管理

### 7.1 记分制度

**记分周期：**
- 记分周期为12个月，从机动车驾驶证初次领取之日起计算
- 满分12分
- 记分周期内累积记分达到12分的，应当参加学习和考试

**记分标准：**

| 违法行为 | 记分 |
|---------|------|
| 驾驶与准驾车型不符的机动车 | 12分 |
| 饮酒后驾驶机动车 | 12分 |
| 造成交通事故后逃逸 | 12分 |
| 违反交通信号灯 | 6分 |
| 超速50%以上 | 12分 |
| 超速20%-50% | 6分 |
| 超速未达20% | 3分 |
| 不按规定让行 | 3分 |
| 违法停车 | 3分 |
| 未系安全带 | 2分 |

### 7.2 学习与考试

**学习要求：**
- 记分达到12分的，应当在15日内到机动车驾驶证核发地或者违法行为地公安机关交通管理部门参加为期7日的道路交通安全法律、法规和相关知识学习
- 学习结束后，应当在20日内参加道路交通安全法律、法规和相关知识考试

**考试要求：**
- 考试合格的，记分予以清除
- 考试不合格的，继续参加学习和考试
- 拒不参加学习，也不接受考试的，由公安机关交通管理部门公告其机动车驾驶证停止使用

### 7.3 记分减免

**学法减分政策：**
- 机动车驾驶人在一个记分周期内，参加公安机关交通管理部门组织的交通安全教育学习、考试或者交通安全公益活动，可以申请减免记分
- 累计最高减免6分
- 减免的记分不适用于交通肇事逃逸、饮酒后驾驶等严重违法行为

**申请条件：**
- 机动车驾驶证在有效期内
- 机动车驾驶人在本记分周期内没有满分记录
- 机动车驾驶人在本记分周期内没有二次以上参加学法减分记录

## 八、当事人权利保障

### 8.1 陈述权和申辩权

**权利内容：**
- 当事人有权进行陈述
- 当事人有权进行申辩
- 当事人有权提供证据
- 公安机关交通管理部门不得因当事人陈述、申辩而加重处罚

### 8.2 听证权

**适用情形：**
- 对个人处以2000元以上罚款的
- 对单位处以10000元以上罚款的
- 吊销机动车驾驶证的

**程序保障：**
- 公安机关交通管理部门应当告知当事人有要求听证的权利
- 当事人要求听证的，应当在收到告知书之日起3日内提出
- 公安机关交通管理部门应当组织听证

### 8.3 行政复议权

**申请条件：**
- 当事人对行政处罚决定不服的
- 当事人认为行政处罚决定侵犯其合法权益的

**申请期限：**
- 当事人应当在收到行政处罚决定书之日起60日内提出行政复议申请

**管辖机关：**
- 向作出行政处罚决定的公安机关交通管理部门的上一级公安机关申请行政复议

### 8.4 行政诉讼权

**起诉条件：**
- 当事人对行政处罚决定不服的
- 当事人对行政复议决定不服的

**起诉期限：**
- 当事人应当在收到行政处罚决定书之日起6个月内提起行政诉讼
- 经行政复议的，应当在收到行政复议决定书之日起15日内提起行政诉讼

### 8.5 要求赔偿权

**赔偿范围：**
- 公安机关交通管理部门违法实施行政处罚造成当事人损失的
- 公安机关交通管理部门违法采取行政强制措施造成当事人损失的
- 公安机关交通管理部门不履行法定职责造成当事人损失的

**赔偿程序：**
- 当事人可以向赔偿义务机关提出赔偿申请
- 赔偿义务机关应当自收到申请之日起2个月内作出是否赔偿的决定
- 当事人对赔偿决定不服的，可以向人民法院提起行政赔偿诉讼

## 九、执法监督

### 9.1 内部监督

**层级监督：**
- 上级公安机关交通管理部门对下级实施监督
- 定期开展执法检查
- 及时纠正违法执法行为

**执法规范：**
- 建立执法记录制度
- 建立执法档案制度
- 建立执法考核制度

### 9.2 外部监督

**社会监督：**
- 公民、法人和其他组织有权对公安机关交通管理部门的执法行为进行监督
- 对违法执法行为有权进行举报、投诉

**媒体监督：**
- 新闻媒体有权对公安机关交通管理部门的执法行为进行舆论监督
- 公安机关交通管理部门应当自觉接受媒体监督

## 十、发展趋势

### 10.1 信息化发展

- 推广网上处理非现场交通违法
- 推广电子送达法律文书
- 建设全国统一的交通违法处理信息平台
- 实现交通违法处理信息全国联网

### 10.2 智能化发展

- 推广智能交通技术监控设备
- 推广人工智能辅助执法
- 建设智能交通违法处理系统
- 实现交通违法处理的自动化

### 10.3 便民化发展

- 简化交通违法处理程序
- 推广"一站式"服务
- 推广"最多跑一次"改革
- 提高交通违法处理效率
