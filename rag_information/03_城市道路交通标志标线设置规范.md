# 城市道路交通标志标线设置规范

## 一、规范概述

《道路交通标志和标线》（GB 5768-2009）是我国道路交通标志和标线设置的国家标准，于2009年发布实施，替代原GB 5768-1999版本。该标准规定了道路交通标志和标线的分类、设置原则、技术要求等内容，适用于公路、城市道路以及虽在单位管辖范围但允许社会机动车通行的场所。

该标准的制定目的是规范道路交通标志和标线的设置，保障道路交通安全和畅通，为道路使用者提供准确、及时的道路信息。

## 二、交通标志体系

### （一）标志分类

道路交通标志按其作用分为主标志和辅助标志两大类。

**主标志包括：**

| 标志类型 | 功能说明 | 形状 | 颜色 |
|---------|---------|------|------|
| 警告标志 | 警告车辆驾驶人、行人前方有危险 | 等边三角形（顶角向上） | 黄底、黑边、黑图案 |
| 禁令标志 | 禁止或限制车辆、行人的交通行为 | 圆形、八角形、顶角向下的等边三角形 | 白底、红圈、红杠、黑图案 |
| 指示标志 | 指示车辆、行人行进方向或地点 | 圆形、方形 | 蓝底、白图案 |
| 指路标志 | 传递道路方向、地点、距离信息 | 方形 | 一般道路：蓝底白字；高速公路：绿底白字 |
| 旅游区标志 | 提供旅游景点方向、距离 | 方形 | 棕底白字 |
| 作业区标志 | 告知道路施工区域 | 方形 | 橙底黑字 |
| 告示标志 | 告知路外设施、安全驾驶信息 | 方形 | 白底、黑字、黑边框 |

**辅助标志：**
- 附设在主标志下，起辅助说明作用
- 形状为长方形
- 白底、黑字、黑边框

### （二）警告标志详细分类

警告标志用于警告驾驶人前方道路有危险，应谨慎行驶。主要包括：

**交叉路口类：**
- 十字交叉路口标志
- T形交叉路口标志
- Y形交叉路口标志
- 环形交叉路口标志

**道路线形类：**
- 急弯路标志（左弯、右弯）
- 反向弯路标志
- 连续弯路标志
- 陡坡标志（上坡、下坡）

**道路状况类：**
- 窄路标志（两侧变窄、左侧变窄、右侧变窄）
- 双向交通标志
- 注意行人标志
- 注意儿童标志
- 注意牲畜标志

**其他危险类：**
- 注意信号灯标志
- 注意落石标志
- 注意横风标志
- 易滑标志
- 傍山险路标志
- 堤坝路标志
- 隧道标志
- 路面不平标志
- 路面高突标志
- 有人看守铁路道口标志
- 无人看守铁路道口标志

### （三）禁令标志详细分类

禁令标志用于禁止或限制车辆、行人的交通行为。主要包括：

**禁止通行类：**
- 禁止通行标志
- 禁止驶入标志
- 禁止机动车通行标志
- 禁止载货汽车通行标志
- 禁止大型客车通行标志
- 禁止小型客车通行标志
- 禁止挂车、半挂车通行标志
- 禁止拖拉机通行标志
- 禁止非机动车通行标志
- 禁止畜力车通行标志
- 禁止人力货运三轮车通行标志
- 禁止人力客运三轮车通行标志
- 禁止人力车通行标志
- 禁止行人通行标志

**限速限重类：**
- 限制速度标志
- 解除限制速度标志
- 限制宽度标志
- 限制高度标志
- 限制质量标志
- 限制轴重标志

**禁止行为类：**
- 禁止超车标志
- 解除禁止超车标志
- 禁止掉头标志
- 禁止左转弯标志
- 禁止右转弯标志
- 禁止鸣喇叭标志
- 禁止停车标志
- 禁止长时停车标志
- 禁止向左转弯标志
- 禁止向右转弯标志

### （四）指示标志详细分类

指示标志用于指示车辆、行人行进方向或地点。主要包括：

**行驶方向类：**
- 直行标志
- 向左转弯标志
- 向右转弯标志
- 直行和向左转弯标志
- 直行和向右转弯标志
- 向左和向右转弯标志

**车道指示类：**
- 靠右侧道路行驶标志
- 靠左侧道路行驶标志
- 立交行驶路线标志
- 环岛行驶标志

**其他指示类：**
- 步行标志
- 鸣喇叭标志
- 最低限速标志
- 单行路标志
- 会车让行标志
- 会车先行标志

## 三、交通标线体系

### （一）标线分类

道路交通标线按功能分为三类：

**1. 指示标线**
- 指示车行道、行车方向、路面边缘、人行道等设施的标线
- 颜色：白色或蓝色

**2. 禁止标线**
- 告示道路交通的遵行、禁止、限制等特殊规定
- 颜色：白色或黄色

**3. 警告标线**
- 促使车辆驾驶人及行人了解道路上的特殊情况
- 颜色：黄色

### （二）纵向标线

**1. 车道分界线**
- 白色虚线：分隔同向行驶的车辆，允许车辆跨越超车或变更车道
- 白色实线：分隔同向行驶的车辆，禁止车辆跨越
- 黄色虚线：分隔对向行驶的交通流，允许车辆在保证安全的情况下跨越
- 黄色实线：分隔对向行驶的交通流，严格禁止车辆跨越
- 双黄实线：分隔对向行驶的交通流，严格禁止车辆跨越或压线行驶

**2. 车行道边缘线**
- 白色实线或虚线
- 指示机动车道的边缘

**3. 导向车道线**
- 白色单实线或单虚线
- 指示车辆按导向方向行驶

### （三）横向标线

**1. 停止线**
- 白色实线
- 表示车辆等候放行的停车位置

**2. 让行线**
- 白色双虚线或单虚线
- 表示车辆必须让主路车辆先行

**3. 人行横道线**
- 白色平行粗实线（斑马线）
- 表示准许行人横穿车行道
- 人行横道宽度一般为4m或6m

**4. 导流线**
- 白色V形线或斜纹线
- 表示车辆须按规定的路线行驶，不得压线或越线行驶

**5. 网状线**
- 黄色网状线
- 表示禁止以任何原因在该区域停车

**6. 停车位标线**
- 白色或黄色标线
- 表示车辆停放位置

### （四）其他标线

**1. 出入口标线**
- 白色标线
- 用于高速公路、快速路的出入口

**2. 路面文字标记**
- 白色文字
- 指示车道功能、限速等信息

**3. 路面图形标记**
- 白色或黄色图形
- 指示特殊路段或区域

## 四、标志设置原则

### （一）总体原则

1. **醒目性原则**：标志应在各种天气条件下能被驾驶人清晰识别
2. **一致性原则**：同一类型标志含义全国统一，避免混淆
3. **规范性原则**：严格按照标准规定的颜色、形状、尺寸设置
4. **简洁性原则**：信息简洁明了，避免信息过载
5. **安全性原则**：保障交通安全，减少交通事故

### （二）设置位置要求

**警告标志：**
- 设置在危险地点前适当位置
- 设置距离根据设计速度确定：
  - 设计速度≥80km/h：设置距离150～250m
  - 设计速度60km/h：设置距离100～150m
  - 设计速度40km/h：设置距离50～100m
  - 设计速度≤30km/h：设置距离20～50m

**禁令标志：**
- 设置在禁止或限制路段的起点处
- 需要提前预告的，应在前方适当位置设置预告标志

**指示标志：**
- 设置在需要指示的地点或路段起点处
- 应在驾驶人需要做出决策前适当距离设置

**指路标志：**
- 设置在交叉口前适当位置
- 高速公路上间距不宜超过30km
- 一般道路上间距不宜超过500m

### （三）标志支撑方式

**1. 柱式标志**
- 单柱式：适用于中小型标志
- 双柱式：适用于大型标志

**2. 悬臂式标志**
- 适用于路侧设置困难的路段
- 标志下缘距路面高度≥5.5m

**3. 门架式标志**
- 适用于高速公路、快速路
- 标志下缘距路面高度≥5.5m

**4. 附着式标志**
- 附着在路灯杆、电线杆等设施上

## 五、标线设置要求

### （一）标线材料要求

- 应具有良好的反光性能
- 应具有良好的耐久性
- 应具有良好的防滑性能
- 颜色应符合标准规定

### （二）标线宽度要求

| 标线类型 | 宽度（cm） |
|---------|-----------|
| 车道分界线（虚线） | 10～15 |
| 车道分界线（实线） | 10～15 |
| 车行道边缘线 | 10～15 |
| 停止线 | 20～40 |
| 人行横道线 | 40～45 |
| 导流线 | 40～45 |

### （三）标线设置注意事项

1. 标线应清晰、连续，不得有断裂、模糊现象
2. 标线应与交通标志配合使用
3. 标线应定期维护，保持良好的视认性
4. 施工期间应设置临时标线或标志

## 六、特殊路段标志标线设置

### （一）学校区域

- 应设置注意儿童标志
- 应设置限速标志（一般限速30km/h）
- 应设置人行横道标线
- 应设置减速标线或振动标线

### （二）医院区域

- 应设置禁止鸣喇叭标志
- 应设置限速标志
- 应注意无障碍设施的标志设置

### （三）施工区域

- 应设置施工警告标志
- 应设置导向标志
- 应设置限速标志
- 应设置临时标线
- 应设置警示灯

### （四）高速公路

- 应设置完善的指路标志系统
- 应设置出口预告标志
- 应设置服务区指示标志
- 应设置紧急电话指示标志

## 七、标志标线的维护管理

### （一）日常维护

- 定期检查标志的完好性
- 清洁标志表面，保持视认性
- 修剪遮挡标志的树枝
- 及时修复损坏的标志

### （二）定期检测

- 每年至少进行一次全面检测
- 检测内容包括：标志的视认性、反光性能、结构安全性
- 检测标线的反光性能、磨损程度

### （三）更新更换

- 标志反光性能下降到规定值以下时应更换
- 标线磨损严重时应重新施划
- 道路条件变化时应更新标志标线
