# 机动车驾驶证申领和使用规定

## 一、概述

《机动车驾驶证申领和使用规定》（公安部令第162号）是规范机动车驾驶证申领和使用的部门规章。该规定最初于1996年发布实施，经过多次修订，最新版本于2021年12月27日发布，自2022年4月1日起施行。

该规定旨在规范机动车驾驶证的申领和使用，保障道路交通安全，保护公民、法人和其他组织的合法权益。规定共七章，包括总则、机动车驾驶证申请、机动车驾驶人考试、发证换证补证、机动车驾驶人管理、法律责任和附则。

机动车驾驶证是驾驶人合法驾驶机动车的法定证件。根据规定，驾驶机动车应当依法取得机动车驾驶证。机动车驾驶证的有效期分为6年、10年和长期三种。驾驶人在有效期内每个记分周期均未记满12分的，换发有效期更长的驾驶证。

## 二、驾驶证类型

### 2.1 准驾车型

机动车驾驶证按照准驾车型分为以下类别：

| 准驾车型 | 代号 | 准予驾驶的其他车型 | 年龄条件 |
|---------|------|------------------|---------|
| 大型客车 | A1 | A3、B1、B2、C1、C2、C3、C4、M | 22-60周岁 |
| 重型牵引挂车 | A2 | B1、B2、C1、C2、C3、C4、M | 22-60周岁 |
| 城市公交车 | A3 | C1、C2、C3、C4 | 20-60周岁 |
| 中型客车 | B1 | C1、C2、C3、C4、M | 20-60周岁 |
| 大型货车 | B2 | C1、C2、C3、C4、M | 20-60周岁 |
| 小型汽车 | C1 | C2、C3、C4 | 18周岁以上 |
| 小型自动挡汽车 | C2 | 无 | 18周岁以上 |
| 低速载货汽车 | C3 | C4 | 18-60周岁 |
| 三轮汽车 | C4 | 无 | 18-60周岁 |
| 残障人士专用小型自动挡载客汽车 | C5 | 无 | 18周岁以上 |
| 轻型牵引挂车 | C6 | 无 | 20-60周岁 |
| 普通三轮摩托车 | D | E、F | 18-60周岁 |
| 普通二轮摩托车 | E | F | 18-60周岁 |
| 轻便摩托车 | F | 无 | 18周岁以上 |
| 轮式专用机械车 | M | 无 | 18-60周岁 |
| 无轨电车 | N | 无 | 20-60周岁 |
| 有轨电车 | P | 无 | 20-60周岁 |

### 2.2 驾驶证有效期

**有效期规定：**
- 初次申领的驾驶证有效期为6年
- 在有效期内每个记分周期均未记满12分的，换发10年有效期的驾驶证
- 在10年有效期内每个记分周期均未记满12分的，换发长期有效的驾驶证

**有效期计算：**
- 驾驶证有效期从核发之日起计算
- 驾驶证有效期届满前90日内应当申请换证
- 逾期未换证的，驾驶证失效

## 三、申请条件

### 3.1 年龄条件

**一般年龄条件：**
- 申请小型汽车、小型自动挡汽车、轻便摩托车准驾车型的，年龄在18周岁以上
- 申请低速载货汽车、三轮汽车、普通三轮摩托车、普通二轮摩托车或者轮式专用机械车准驾车型的，年龄在18周岁以上，60周岁以下
- 申请城市公交车、中型客车、大型货车、轻型牵引挂车准驾车型的，年龄在20周岁以上，60周岁以下
- 申请大型客车、重型牵引挂车准驾车型的，年龄在22周岁以上，60周岁以下

**特殊年龄条件：**
- 年龄在60周岁以上的，不得驾驶大型客车、重型牵引挂车、城市公交车、中型客车、大型货车、轮式专用机械车
- 年龄在70周岁以上的，不得驾驶低速载货汽车、三轮汽车、轻型牵引挂车、普通三轮摩托车、普通二轮摩托车
- 年龄在70周岁以上申请小型汽车、小型自动挡汽车、轻便摩托车准驾车型的，应当通过记忆力、判断力、反应力等能力测试

### 3.2 身体条件

**一般身体条件：**
- 身高：申请大型客车、重型牵引挂车、城市公交车、大型货车、无轨电车准驾车型的，身高为155厘米以上。申请中型客车准驾车型的，身高为150厘米以上
- 视力：申请大型客车、重型牵引挂车、城市公交车、中型客车、大型货车、无轨电车或者有轨电车准驾车型的，两眼裸视力或者矫正视力达到对数视力表5.0以上。申请其他准驾车型的，两眼裸视力或者矫正视力达到对数视力表4.9以上
- 辨色力：无红绿色盲
- 听力：两耳分别距音叉50厘米能辨别声源方向
- 上肢：双手拇指健全，每只手其他手指必须有三指健全，肢体和手指运动功能正常
- 下肢：双下肢健全且运动功能正常，不等长度不得大于5厘米
- 躯干、颈部：无运动功能障碍

**特殊身体条件：**
- 申请C5准驾车型的，应当符合下列身体条件：右下肢、双下肢缺失或者丧失运动功能但能够自主坐立，且上肢符合规定要求的
- 申请C2准驾车型的，应当符合下列身体条件：左下肢缺失或者丧失运动功能的

### 3.3 禁止申请情形

有下列情形之一的，不得申请机动车驾驶证：

- 有器质性心脏病、癫痫病、美尼尔氏症、眩晕症、癔病、震颤麻痹、精神病、痴呆以及影响肢体活动的神经系统疾病等妨碍安全驾驶疾病的
- 三年内有吸食、注射毒品行为或者解除强制隔离戒毒措施未满三年，以及长期服用依赖性精神药品成瘾尚未戒除的
- 造成交通事故后逃逸构成犯罪的
- 饮酒后或者醉酒驾驶机动车发生重大交通事故构成犯罪的
- 醉酒驾驶机动车或者饮酒后驾驶营运机动车依法被吊销机动车驾驶证未满五年的
- 醉酒驾驶营运机动车依法被吊销机动车驾驶证未满十年的
- 因其他情形依法被吊销机动车驾驶证未满二年的
- 驾驶许可依法被撤销未满三年的
- 法律、行政法规规定的其他情形

## 四、考试制度

### 4.1 考试科目

机动车驾驶人考试分为以下科目：

**科目一：道路交通安全法律、法规和相关知识考试**
- 考试内容：道路交通安全法律、法规和规章，交通信号及其含义，安全行车、文明驾驶知识等
- 考试方式：计算机考试
- 考试时间：45分钟
- 合格标准：90分以上（满分100分）

**科目二：场地驾驶技能考试**
- 考试内容：倒车入库、坡道定点停车和起步、侧方停车、曲线行驶、直角转弯等
- 考试方式：场地驾驶
- 合格标准：80分以上（满分100分）

**科目三：道路驾驶技能考试**
- 考试内容：上车准备、起步、直线行驶、加减挡位操作、变更车道、靠边停车、直行通过路口、路口左转弯、路口右转弯、通过人行横道线、通过学校区域、通过公共汽车站、会车、超车、掉头、夜间行驶等
- 考试方式：道路驾驶
- 合格标准：90分以上（满分100分）

**科目四：安全文明驾驶常识考试**
- 考试内容：安全文明驾驶操作要求、恶劣气象和复杂道路条件下的安全驾驶知识、爆胎等紧急情况下的临危处置方法以及发生交通事故后的处置知识等
- 考试方式：计算机考试
- 考试时间：30分钟
- 合格标准：90分以上（满分100分）

### 4.2 考试要求

**考试预约：**
- 申请人可以通过互联网交通安全综合服务管理平台预约考试
- 申请人可以通过"交管12123"手机APP预约考试
- 申请人可以到公安机关交通管理部门窗口预约考试

**考试次数：**
- 每个科目考试一次，考试不合格的，可以补考一次
- 不参加补考或者补考仍不合格的，本次考试终止
- 申请人应当在十日后重新预约考试
- 在驾驶技能准考证明有效期内，科目二和科目三道路驾驶技能考试预约考试的次数不得超过五次
- 第五次预约考试仍不合格的，已考试合格的其他科目成绩作废

**考试纪律：**
- 申请人应当遵守考试纪律
- 不得携带与考试有关的资料
- 不得由他人代考
- 违反考试纪律的，取消考试资格

### 4.3 便民措施

**全国"一证通考"：**
- 持居民身份证可以在全国任一地申请小型汽车驾驶证
- 无需提交居住证或者居住登记凭证

**异地分科目考试：**
- 申请人申领小型汽车驾驶证期间已通过部分科目考试后，因工作、学习、生活等原因需要变更居住地的，可以在全国范围内申请变更一次考试地
- 申请人可以继续在现居住地预约参加剩余科目考试

**自学直考：**
- 在有条件的城市，允许个人自学直考小型汽车驾驶证
- 自学直考需要满足一定条件
- 自学直考需要使用加装安全辅助装置的自备车辆

## 五、换证补证

### 5.1 换证

**换证情形：**
- 有效期满换证
- 达到规定年龄换证
- 自愿降低准驾车型换证
- 机动车驾驶人信息发生变化换证
- 机动车驾驶证损毁换证

**换证程序：**
1. 机动车驾驶人向机动车驾驶证核发地或者核发地以外的车辆管理所申请换证
2. 提交申请表、身份证明、机动车驾驶证、身体条件证明等材料
3. 车辆管理所审核材料
4. 符合条件的，换发机动车驾驶证

**换证期限：**
- 有效期满换证应当在有效期满前90日内申请
- 达到规定年龄换证应当在年龄达到后30日内申请
- 逾期未换证的，驾驶证失效

### 5.2 补证

**补证情形：**
- 机动车驾驶证遗失的
- 机动车驾驶证损毁的

**补证程序：**
1. 机动车驾驶人向机动车驾驶证核发地或者核发地以外的车辆管理所申请补证
2. 提交申请表、身份证明等材料
3. 车辆管理所审核材料
4. 符合条件的，补发机动车驾驶证

**补证要求：**
- 机动车驾驶人应当提交身份证明
- 机动车驾驶人应当提交机动车驾驶证遗失的书面声明
- 补发机动车驾驶证后，原机动车驾驶证作废

## 六、驾驶人管理

### 6.1 记分制度

**记分周期：**
- 记分周期为12个月，从机动车驾驶证初次领取之日起计算
- 满分12分

**记分标准：**

| 违法行为 | 记分 |
|---------|------|
| 驾驶与准驾车型不符的机动车 | 12分 |
| 饮酒后驾驶机动车 | 12分 |
| 造成交通事故后逃逸 | 12分 |
| 违反交通信号灯 | 6分 |
| 超速50%以上 | 12分 |
| 超速20%-50% | 6分 |
| 超速未达20% | 3分 |
| 不按规定让行 | 3分 |
| 违法停车 | 3分 |
| 未系安全带 | 2分 |

**记分处理：**
- 记分达到12分的，应当参加学习和考试
- 记分达到12分拒不参加学习的，驾驶证停止使用
- 记分未达到12分的，记分予以清除

### 6.2 审验制度

**审验情形：**
- 持有大型客车、重型牵引挂车、城市公交车、中型客车、大型货车驾驶证的驾驶人，应当在每个记分周期结束后三十日内到公安机关交通管理部门接受审验
- 持有其他准驾车型驾驶证的驾驶人，发生交通事故造成人员死亡承担同等以上责任未被吊销机动车驾驶证的，应当在本记分周期结束后三十日内到公安机关交通管理部门接受审验

**审验内容：**
- 道路交通安全违法行为、交通事故处理情况
- 身体条件情况
- 道路交通安全违法行为记分及记满12分后参加学习和考试情况

**审验程序：**
1. 驾驶人向公安机关交通管理部门提交审验申请
2. 提交身份证明、机动车驾驶证、身体条件证明等材料
3. 公安机关交通管理部门审核材料
4. 符合条件的，在机动车驾驶证上签注审验合格

### 6.3 降级制度

**降级情形：**
- 发生交通事故造成人员死亡，承担同等以上责任，未构成犯罪的
- 在一个记分周期内有记满12分记录的
- 连续三个记分周期不参加审验的

**降级程序：**
1. 公安机关交通管理部门通知驾驶人办理降级换证
2. 驾驶人在规定期限内办理降级换证
3. 车辆管理所换发降级后的机动车驾驶证

**降级后果：**
- 驾驶证降级后，驾驶人不得驾驶原准驾车型的机动车
- 驾驶人需要重新申请增加准驾车型的，应当符合增加准驾车型的条件

### 6.4 实习期管理

**实习期规定：**
- 机动车驾驶人初次申领机动车驾驶证后的12个月为实习期
- 在实习期内驾驶机动车的，应当在车身后部粘贴或者悬挂统一式样的实习标志

**实习期限制：**
- 在实习期内不得驾驶公共汽车、营运客车或者执行任务的警车、消防车、救护车、工程救险车以及载有爆炸物品、易燃易爆化学物品、剧毒或者放射性等危险物品的机动车
- 在实习期内驾驶机动车上高速公路行驶，应当由持相应或者包含其准驾车型驾驶证三年以上的驾驶人陪同

## 七、法律责任

### 7.1 无证驾驶

**无证驾驶的情形：**
- 未取得机动车驾驶证驾驶机动车的
- 机动车驾驶证被吊销期间驾驶机动车的
- 机动车驾驶证被暂扣期间驾驶机动车的

**处罚标准：**
- 处200元以上2000元以下罚款
- 可以并处15日以下拘留

### 7.2 驾驶证造假

**造假情形：**
- 伪造、变造机动车驾驶证的
- 使用伪造、变造的机动车驾驶证的
- 使用其他车辆的机动车驾驶证的

**处罚标准：**
- 伪造、变造机动车驾驶证的，处2000元以上5000元以下罚款
- 使用伪造、变造的机动车驾驶证的，处2000元以上5000元以下罚款
- 使用其他车辆的机动车驾驶证的，处2000元以上5000元以下罚款

### 7.3 违规驾驶

**违规情形：**
- 驾驶与准驾车型不符的机动车的
- 驾驶拼装或者已达报废标准的机动车的
- 驾驶未悬挂机动车号牌的机动车的

**处罚标准：**
- 驾驶与准驾车型不符的机动车的，处200元以上2000元以下罚款，记12分
- 驾驶拼装或者已达报废标准的机动车的，处200元以上2000元以下罚款，吊销驾驶证
- 驾驶未悬挂机动车号牌的机动车的，处200元罚款，记9分

## 八、便民措施

### 8.1 电子驾驶证

**电子驾驶证的特点：**
- 与纸质驾驶证具有同等法律效力
- 可以通过"交管12123"手机APP申领
- 可以在路面查验、违法处理、事故处理等场景使用
- 可以在办理交管业务、保险理赔、租车等场景使用

**申领方式：**
- 下载"交管12123"手机APP
- 注册并登录
- 进入"驾驶证电子版"模块
- 按照提示申领电子驾驶证

### 8.2 网上办理

**网上办理业务：**
- 驾驶证补换领
- 驾驶证审验
- 驾驶证延期
- 驾驶证信息变更
- 驾驶证注销

**网上办理流程：**
1. 登录互联网交通安全综合服务管理平台
2. 选择需要办理的业务
3. 提交申请材料
4. 等待审核
5. 邮寄送达或者自取

### 8.3 异地办理

**异地办理业务：**
- 驾驶证补换领
- 驾驶证审验
- 驾驶证延期
- 驾驶证信息变更
- 驾驶证注销

**异地办理条件：**
- 持居民身份证可以在全国任一地办理
- 无需提交居住证或者居住登记凭证
