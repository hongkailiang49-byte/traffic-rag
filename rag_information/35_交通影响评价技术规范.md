# 交通影响评价技术规范

## 1. 概述

交通影响评价（Traffic Impact Assessment，TIA）是研究新建项目或城市土地利用变更对交通系统影响的技术方法，通过预测新增交通需求对周边路网的影响程度，提出交通改善对策以优化资源配置，促进土地开发与交通协调发展。交通影响评价简称"交评"，是交通源头治理的重要措施和手段。

交通影响评价的核心目的是规范交通影响评价工作，提升道路通行条件，保障道路交通安全、有序、畅通；科学、准确地进行交通影响评价，促进土地开发与交通协调发展。它也是保证大型项目开发建设不导致开发对象周边交通服务水平下降、避免土地超强开发的重要规划控制措施。

## 2. 发展历程

### 2.1 国际起源

交通影响评价的思想源于环境影响评价。1969年美国《国家环境政策法》最早从法律上确立了环境影响评价制度，随后该制度在100多个国家不同程度地得以实施和推广。美国是最早开展交通影响评价的国家，20世纪70年代开始在加利福尼亚州等地区实施。

### 2.2 国内发展

在我国，交通影响评价工作的法律基础在2011年才得以确立。2012年，《国务院关于城市优先发展公共交通的指导意见》明确要求落实城市建设项目交通影响评价制度。同年，江苏省住房和城乡建设厅与公安厅联合印发《关于加强城市规划交通影响评价工作的通知》。

此后，各地陆续制定并更新地方管理办法，推动制度深化与细化：
- **苏州市**：2015年3月1日起施行《苏州市交通影响评价管理办法》
- **常州市**：2023年制定《常州市交通影响评价管理办法》
- **昆山市**：2022年6月6日起实施新版《交通影响评价编制与管理细则》
- **湛江市**：2023年12月23日印发《湛江市交通影响评价管理办法（试行）》
- **潮州市**：2023年11月1日起实施新版《城市建设项目交通影响评价管理办法》

## 3. 评价类型与阶段

### 3.1 评价类型

交通影响评价通常划分为两种类型：

#### 3.1.1 规划阶段交通影响评价

在控制性详细规划编制阶段进行的交通影响评价，主要分析规划方案对周边交通系统的影响，为规划方案的优化提供依据。

#### 3.1.2 建设项目交通影响评价

在建设项目审批阶段进行的交通影响评价，主要分析项目建成后对周边交通的影响，提出交通改善措施。

### 3.2 评价阶段

实施阶段可细分为：
- **选址/规划条件阶段**：分析项目选址和规划条件的交通可行性
- **建设工程设计方案阶段**：分析设计方案的交通影响
- **占道施工期**：分析施工期间对交通的影响

## 4. 评价启动阈值

### 4.1 阈值设定原则

各城市根据自身情况制定明确的启动阈值，通常与项目区位、类别和建筑规模直接挂钩。

### 4.2 典型阈值标准

| 项目类型 | 常州市 | 湛江市 | 苏州市 |
|---------|-------|-------|-------|
| 住宅（核心区域） | - | - | ≥2万m² |
| 商业（核心区域） | ≥3万m² | - | ≥1万m² |
| 公共建筑（重要地段） | - | ≥2万m² | - |
| 居住类（一般区域） | ≥5万m² | ≥5万m² | ≥5万m² |
| 商业类（一般区域） | ≥2万m² | ≥2万m² | ≥2万m² |

部分城市将启动阈值与容积率挂钩，高容积率项目需要进行交通影响评价。

## 5. 评价范围确定

### 5.1 评价范围

评价范围通常由项目所在城市主干道围合区域构成。重大项目实施时可适当扩展至交通显著影响区。

### 5.2 确定方法

评价范围的确定应考虑以下因素：
- 项目规模和性质
- 项目周边道路网络结构
- 交通影响的传播范围
- 主要交通集散通道

一般情况下，评价范围为项目周边500-1000米范围内的主要道路围合区域。对于大型项目，评价范围可扩展至2000-3000米。

## 6. 评价技术内容

### 6.1 项目概述

项目概述应包括：
- 项目名称、位置、用地面积
- 建设内容、建筑面积、容积率
- 建设时序、投入使用时间
- 停车设施配置情况

### 6.2 现状交通分析

#### 6.2.1 道路网络现状

- 周边道路的等级、断面形式、车道数
- 交叉口形式和控制方式
- 道路服务水平和拥堵状况

#### 6.2.2 公共交通现状

- 公交线路和站点分布
- 轨道交通站点分布
- 公交服务水平

#### 6.2.3 停车设施现状

- 周边公共停车场分布
- 路内停车情况
- 停车供需状况

#### 6.2.4 慢行交通现状

- 人行道和非机动车道设施
- 人行过街设施
- 慢行交通环境

### 6.3 交通需求预测

#### 6.3.1 背景交通量预测

背景交通量是指不考虑拟建项目影响时，周边道路的交通量。预测方法包括：
- 趋势外推法
- 四阶段预测法
- 交通模型预测

#### 6.3.2 项目交通量预测

项目交通量是指拟建项目产生的新增交通量。预测步骤包括：

1. **交通生成**：根据项目性质和规模，利用交通吸发率计算项目产生的交通量

   **交通吸发率**是指单位建筑面积或单位用地面积在高峰小时产生的交通量。不同项目类型的吸发率差异较大：

   | 项目类型 | 吸发率（人次/百m²·高峰小时） |
   |---------|--------------------------|
   | 住宅 | 0.5-1.5 |
   | 办公 | 0.8-2.0 |
   | 商业 | 1.0-3.0 |
   | 医院 | 0.8-2.5 |
   | 学校 | 0.5-1.5 |

2. **方式划分**：确定各种出行方式的比例

   | 出行方式 | 典型比例 |
   |---------|---------|
   | 小汽车 | 30-50% |
   | 公共交通 | 20-40% |
   | 非机动车 | 10-20% |
   | 步行 | 10-20% |

3. **交通分布**：确定项目交通量在周边道路的分布
4. **交通分配**：将交通量分配到具体的路段和交叉口

#### 6.3.3 叠加交通量

叠加交通量 = 背景交通量 + 项目交通量

### 6.4 交通影响程度评价

#### 6.4.1 路段服务水平评价

分析叠加交通量后各路段的服务水平变化：
- V/C比（交通量/通行能力）
- 服务水平等级
- 服务水平变化幅度

#### 6.4.2 交叉口服务水平评价

分析叠加交通量后各交叉口的服务水平变化：
- 各进口道延误
- 交叉口整体延误
- 服务水平等级

#### 6.4.3 影响程度判定

一般认为，当项目导致周边道路服务水平下降超过一个等级时，影响程度较大，需要采取改善措施。

### 6.5 交通改善措施

#### 6.5.1 出入口设置

- 出入口位置和数量
- 出入口与交叉口的距离
- 出入口转向限制

#### 6.5.2 内部交通组织

- 内部车行流线
- 人车分流
- 停车场出入口组织

#### 6.5.3 外部交通组织

- 周边道路信号优化
- 交通组织调整
- 交通诱导措施

#### 6.5.4 停车设施配置

- 停车位数量
- 停车场布局
- 充电设施配置

#### 6.5.5 公共交通衔接

- 公交站点设置
- 公交接驳线路
- 慢行交通接驳

#### 6.5.6 慢行交通改善

- 人行道拓宽
- 非机动车道完善
- 人行过街设施增设

### 6.6 结论与建议

- 评价结论：项目对周边交通的影响程度
- 改善建议：需要采取的交通改善措施
- 实施建议：改善措施的实施主体和时序

## 7. 报告编制要求

### 7.1 编制依据

- 《建设项目交通影响评价技术标准》（CJJ/T 141-2010）
- 地方交通影响评价管理办法
- 地方交通影响评价技术指引

### 7.2 报告内容

交通影响评价报告应包括：
1. 项目概述
2. 评价范围和依据
3. 现状交通分析
4. 交通需求预测
5. 交通影响评价
6. 交通改善措施
7. 结论与建议
8. 附图附表

### 7.3 数据要求

- 现状交通数据：交通量、速度、延误等
- 道路网络数据：道路等级、断面、交叉口等
- 土地利用数据：周边用地性质、建筑面积等
- 规划数据：规划道路、规划用地等

## 8. 审查与管理

### 8.1 审查机制

审查工作多由自然资源和规划主管部门牵头，会同公安、交通、住建等部门进行联合审查，对于复杂项目还需组织专家论证。

### 8.2 编制单位管理

对承担交通影响评价报告编制的单位有明确的管理要求，通常要求其具备城乡规划设计相应资质，或设有交通规划专业并具备专业技术力量。多地普遍建立了对编制单位的信用考核与管理制度。

### 8.3 评价结论落实

交通影响评价提出的改善措施需要明确实施主体和时序：
- **开发主体实施**：出入口设置、内部交通组织、停车设施等
- **政府实施**：外部道路改善、交通信号优化等
- **同步实施**：与项目同步建设的配套交通设施

## 9. 发展趋势

### 9.1 区域交通评估

交通影响评价的应用形式从单一项目评估向区域整体评估拓展。北京市于2021年试行《北京市区域交通评估实施细则》，以街区为单元评估规划实施的交通匹配度，简化区域内单个项目的交评审查。

### 9.2 交通影响后评价

昆山市在全国率先开展交评后评估工作，通过出台《昆山市交通影响评价编制与管理细则》和审查指南，建立了从源头把关、过程管控到末端考评的全流程监管机制。

### 9.3 技术方法创新

- **分区中观模型**：融合"静态分配"和"动态仿真"于一体的评价方法
- **大数据分析**：利用手机信令、GPS轨迹等大数据提高评价精度
- **交通仿真技术**：利用微观交通仿真验证改善措施的效果
- **参数动态更新**：建立交评参数动态更新机制

### 9.4 标准体系完善

- 建立统一基础数据、统一交通模型、统一评估平台的技术工作机制
- 完善交通影响评价技术标准和规范
- 加强编制单位和人员的资质管理

## 10. 存在问题与对策

### 10.1 主要问题

1. **操作形式化**：部分地方交评工作流于形式，为评价而评价
2. **设计脱节**：建筑设计与交通设计环节脱节，缺乏有效衔接
3. **落实困难**：改善措施涉及多个职能部门，部门间缺乏有效沟通与统筹协调
4. **市场混乱**：编制单位专业门槛不统一，存在"不追专业、只看价格"的局面
5. **客观性不足**：受开发商委托可能影响报告的客观性

### 10.2 对策建议

1. **建立沟通机制**：建立相关部门沟通合作机制，明确各部门职责
2. **引入第三方**：鼓励引入第三方专业化队伍开展影响评价或技术审查工作
3. **强化数据真实性**：加强基础数据的真实性以及全面性
4. **加强微观设计**：加强微观交通组织方案设计
5. **建立监督机制**：建立规范化的监督机制，确保评价结论落实
