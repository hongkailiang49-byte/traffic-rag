# 城市道路工程设计规范

## 一、规范概述

《城市道路工程设计规范》（CJJ 37-2012）是中华人民共和国住房和城乡建设部发布的行业标准，于2012年发布实施。该规范是我国城市道路设计的基本技术依据，适用于城市新建、改建和扩建的道路工程设计。

该规范的制定目的是规范城市道路工程设计，合理确定道路建设规模和技术标准，保证道路工程建设质量，提高城市道路服务水平。

## 二、道路分级与分类

### （一）按功能分类

城市道路按其在路网中的地位、交通功能以及对沿线建筑物的服务功能分为四类：

| 道路等级 | 功能定位 | 主要特点 |
|---------|---------|---------|
| 快速路 | 城市长距离交通服务 | 全部控制出入，设计速度高 |
| 主干路 | 城市各分区之间的交通联系 | 连接各分区，交通量大 |
| 次干路 | 城市各分区内的交通联系 | 集散交通，服务功能 |
| 支路 | 城市各街区的交通联系 | 服务功能为主 |

### （二）按技术等级分类

| 技术等级 | 适用道路 | 设计速度（km/h） |
|---------|---------|-----------------|
| I级 | 快速路 | 60、80、100 |
| II级 | 主干路 | 40、50、60 |
| III级 | 次干路 | 30、40、50 |
| IV级 | 支路 | 20、30、40 |

### （三）设计速度

| 道路等级 | 设计速度（km/h） |
|---------|-----------------|
| 快速路 | 100、80、60 |
| 主干路 | 60、50、40 |
| 次干路 | 50、40、30 |
| 支路 | 40、30、20 |

## 三、道路通行能力

### （一）设计服务水平

| 服务水平 | 交通流状态 | 适用道路 |
|---------|-----------|---------|
| 一级 | 自由流 | 特殊要求 |
| 二级 | 稳定流 | 快速路设计采用 |
| 三级 | 稳定流上限 | 主干路设计采用 |
| 四级 | 不稳定流 | 次干路、支路设计采用 |

### （二）设计通行能力

**1. 车道通行能力**

| 设计速度（km/h） | 基本通行能力（pcu/h） | 设计通行能力（pcu/h） |
|-----------------|---------------------|---------------------|
| 100 | 2200 | 2000 |
| 80 | 2100 | 1800 |
| 60 | 1800 | 1550 |
| 50 | 1700 | 1400 |
| 40 | 1650 | 1300 |
| 30 | 1600 | 1100 |
| 20 | 1400 | 900 |

**2. 交叉口通行能力**

- 信号控制交叉口通行能力根据信号配时计算
- 无信号控制交叉口通行能力根据让行规则计算

### （三）道路服务水平

| 服务水平 | V/C比 | 交通状态 |
|---------|-------|---------|
| A | ≤0.35 | 自由流 |
| B | 0.35～0.55 | 稳定流 |
| C | 0.55～0.75 | 稳定流上限 |
| D | 0.75～0.90 | 接近不稳定流 |
| E | 0.90～1.00 | 不稳定流 |
| F | >1.00 | 强制流 |

## 四、横断面设计

### （一）道路横断面组成

城市道路横断面一般由以下部分组成：

| 组成部分 | 功能说明 |
|---------|---------|
| 车行道 | 供车辆行驶 |
| 人行道 | 供行人通行 |
| 分隔带 | 分隔对向或同向交通 |
| 路缘带 | 车行道边缘 |
| 绿化带 | 绿化美化 |
| 设施带 | 设置交通设施 |

### （二）车道宽度

| 车道类型 | 宽度（m） | 说明 |
|---------|----------|------|
| 小客车道 | 3.25～3.50 | 以小客车为主 |
| 大型车道 | 3.50～3.75 | 以大型车为主 |
| 公交专用道 | 3.50～3.75 | 公交车专用 |
| 非机动车道 | 2.50～4.00 | 非机动车行驶 |
| 人行道 | 2.00～5.00 | 行人通行 |

### （三）路缘带宽度

| 设计速度（km/h） | 路缘带宽度（m） |
|-----------------|----------------|
| ≥60 | 0.50 |
| 50 | 0.50 |
| 40 | 0.25 |
| 30 | 0.25 |
| 20 | 0.25 |

### （四）分隔带宽度

| 分隔带类型 | 最小宽度（m） | 说明 |
|-----------|--------------|------|
| 中央分隔带 | 2.00（5.00） | 有绿化时≥5.00 |
| 机非分隔带 | 1.50（2.50） | 有绿化时≥2.50 |
| 人行道与车行道分隔 | 1.50 | 可设置绿化 |

### （五）人行道宽度

| 道路等级 | 人行道宽度（m） | 说明 |
|---------|---------------|------|
| 快速路 | — | 一般不设人行道 |

| 次干路 | 3.00～5.00 | 根据人流确定 |
| 支路 | 2.00～4.00 | 根据人流确定 |

## 五、平面设计

### （一）平面线形设计原则

- 平面线形应与地形、地物相适应
- 线形应连续、圆滑

## 七、路面设计

### （一）路面类型选择

| 路面类型 | 适用条件 | 特点 |
|---------|---------|------|
| 沥青路面 | 各级城市道路 | 平整、舒适、易维修 |
| 水泥混凝土路面 | 重载交通道路 | 强度高、耐久性好 |
| 砌块路面 | 人行道、广场 | 美观、易更换 |

### （二）沥青路面设计

**1. 路面结构组合**

| 结构层 | 厚度（cm） | 材料 |
|-------|-----------|------|
| 上面层 | 4～5 | SMA、改性沥青 |
| 中面层 | 5～6 | 中粒式沥青 |
| 下面层 | 6～8 | 粗粒式沥青 |
| 基层 | 20～40 | 水泥稳定碎石 |
| 底基层 | 15～20 | 石灰粉煤灰土 |

**2. 路面厚度计算**

路面厚度应根据交通量、土基强度、材料参数等计算确定。

### （三）水泥混凝土路面设计

**1. 板厚设计**

| 交通等级 | 板厚（cm） |
|---------|-----------|
| 特重交通 | 26～30 |
| 重交通 | 24～28 |
| 中等交通 | 22～26 |
| 轻交通 | 20～24 |

**2. 接缝设计**

| 接缝类型 | 间距（m） | 说明 |
|---------|----------|------|
| 横向缩缝 | 4～6 | 控制横向裂缝 |
| 横向胀缝 | 按设计确定 | 适应膨胀 |
| 纵向施工缝 | 按车道设置 | 分车道施工 |

## 九、桥涵与隧道

### （一）桥涵设计要求

- 桥涵设计应与道路等级相适应
- 桥涵荷载标准应满足交通需求
- 桥涵净空应满足通行要求

### （二）隧道设计要求

- 隧道设计应满足安全要求
- 隧道通风、照明应满足使用要求
- 隧道消防设施应完善

## 十一、绿化与景观

### （一）绿化设计原则

- 与道路功能相适应
- 与周边环境相协调
- 满足交通安全要求
- 便于养护管理

### （二）绿化带宽度
