# 危险货物道路运输管理规定

## 一、概述

危险货物道路运输是现代物流体系的重要组成部分，同时也是安全生产监管的重点领域。根据《道路危险货物运输管理规定》（交通运输部令2019年第42号修订）和《危险化学品安全管理条例》（国务院令第591号），危险货物道路运输实行严格的许可制度和安全管理制度，旨在保障运输安全，防止和减少运输事故，保护人民群众生命财产安全和环境安全。

危险货物是指具有爆炸、易燃、毒害、感染、腐蚀、放射性等危险特性，在运输、储存、生产、经营、使用和处置中，容易造成人身伤亡、财产损毁或者环境污染而需要特别防护的物质和物品。

## 二、危险货物分类

### （一）危险货物分类体系

根据《危险货物分类和品名编号》（GB 6944）和联合国《关于危险货物运输的建议书》，危险货物分为以下九类：

| 类别 | 名称 | 典型货物 |
|------|------|---------|
| 第1类 | 爆炸品 | 炸药、雷管、烟花爆竹 |
| 第2类 | 气体 | 液化石油气、氧气、氯气 |
| 第3类 | 易燃液体 | 汽油、酒精、油漆 |
| 第4类 | 易燃固体、易于自燃的物质、遇水放出易燃气体的物质 | 红磷、金属钠、电石 |
| 第5类 | 氧化性物质和有机过氧化物 | 高锰酸钾、过氧化氢 |
| 第6类 | 毒性物质和感染性物质 | 农药、医疗废物 |
| 第7类 | 放射性物质 | 铀、钴-60 |
| 第8类 | 腐蚀性物质 | 硫酸、盐酸、氢氧化钠 |
| 第9类 | 杂项危险物质和物品 | 石棉、锂电池 |

### （二）危险货物包装类别

根据危险程度，危险货物包装分为三个类别：

| 包装类别 | 代号 | 危险程度 |
|---------|------|---------|
| I类包装 | X | 高度危险 |
| II类包装 | Y | 中度危险 |
| III类包装 | Z | 低度危险 |

## 三、运输许可管理

### （一）企业资质要求

申请从事危险货物道路运输的企业，应当具备以下条件：

1. **车辆要求**：
   - 有符合要求的专用车辆及设备
   - 车辆技术等级达到一级
   - 配备符合标准的通讯工具
   - 配备必要的应急处理器材和防护用品

2. **人员要求**：
   - 有取得从业资格的驾驶人员
   - 有取得从业资格的押运人员
   - 有取得从业资格的装卸管理人员
   - 驾驶人员年龄不超过60周岁，3年内无重大以上交通责任事故

3. **场地要求**：
   - 有固定的办公场所
   - 有符合规定的停车场地
   - 停车场地与经营范围、车辆数量相适应

4. **管理制度**：
   - 有健全的安全生产管理制度
   - 有完善的事故应急预案
   - 有规范的运输操作规程

### （二）许可程序

1. **申请**：向所在地设区的市级交通运输主管部门提出申请
2. **审查**：交通运输主管部门对申请材料进行审查
3. **决定**：符合条件的，颁发《道路运输经营许可证》
4. **发证**：在许可证件上注明经营范围

### （三）车辆要求

#### 1. 车辆技术条件

- 车辆技术等级达到一级
- 车辆外廓尺寸、轴荷和质量符合国家标准
- 配备符合标准的行驶记录仪或卫星定位装置
- 配备必要的应急处理器材和防护用品

#### 2. 车辆标志标识

- 悬挂符合标准的危险货物运输标志灯和标志牌
- 车身喷涂危险货物运输标识
- 罐体标明货物名称和容积

#### 3. 罐式车辆特殊要求

- 罐体经检验合格并在有效期内
- 罐体与车辆固定连接可靠
- 配备紧急切断装置
- 罐体阀门、管路密封良好

## 四、从业人员管理

### （一）从业资格条件

从事危险货物道路运输的驾驶人员、押运人员和装卸管理人员，应当取得相应的从业资格证。

#### 1. 驾驶人员

- 取得相应机动车驾驶证
- 年龄不超过60周岁
- 3年内无重大以上交通责任事故
- 取得危险货物运输从业资格证

#### 2. 押运人员

- 年龄不超过60周岁
- 具有初中以上学历
- 了解危险货物的性质和危害
- 掌握应急处置方法
- 取得危险货物押运从业资格证

#### 3. 装卸管理人员

- 年龄不超过60周岁
- 具有初中以上学历
- 掌握危险货物装卸操作规程
- 取得危险货物装卸管理从业资格证

### （二）培训要求

1. **岗前培训**：上岗前应当接受不少于40学时的安全培训
2. **继续教育**：每年应当接受不少于24学时的继续教育
3. **专项培训**：运输新品种危险货物前，应当接受专项培训

## 五、运输作业规范

### （一）托运环节

#### 1. 托运人责任

- 如实告知承运人所托运危险货物的品名、性质、数量和应急处置方法
- 按照规定对危险货物进行包装
- 在包装上粘贴或拴挂危险货物标志
- 提供安全技术说明书

#### 2. 托运单据

- 危险货物托运单
- 安全技术说明书
- 包装检验证书
- 装箱证明书（集装箱运输）

### （二）装载环节

#### 1. 装载前检查

- 检查车辆技术状况
- 检查罐体是否在检验有效期内
- 检查应急器材和防护用品是否齐全有效
- 检查车辆标志标识是否清晰完整

#### 2. 装载要求

- 不得超载、超限
- 货物固定牢靠，防止运输过程中移动
- 不同性质的危险货物不得混装
- 装载完毕后检查密封性

### （三）运输环节

#### 1. 行驶要求

- 按照规定的路线和时间行驶
- 保持安全车速，不得超速行驶
- 不得在人口密集区域停留
- 不得进入禁止通行的区域

#### 2. 停放要求

- 不得在居民区、学校、医院等人员密集区域停放
- 停放时应当留人看守
- 夜间停放应当选择安全地点

#### 3. 途中检查

- 每行驶2小时应当停车检查一次
- 检查货物固定情况
- 检查车辆技术状况
- 检查罐体和阀门密封情况

### （四）卸载环节

- 按照操作规程进行卸载
- 卸载区域应当设置警示标志
- 卸载完毕后检查车辆和罐体状况
- 做好卸载记录

## 六、安全管理制度

### （一）安全生产责任制

企业应当建立健全安全生产责任制，明确各级管理人员和从业人员的安全职责：

1. 企业主要负责人是安全生产第一责任人
2. 设置安全生产管理机构或配备专职安全管理人员
3. 建立安全生产责任考核制度

### （二）安全操作规程

企业应当制定完善的安全操作规程，包括：

1. 车辆安全检查规程
2. 货物装载和卸载操作规程
3. 运输途中安全操作规程
4. 应急处置操作规程

### （三）应急预案管理

企业应当制定危险货物运输事故应急预案，内容包括：

1. 应急组织机构和职责
2. 应急响应程序
3. 应急处置措施
4. 应急物资和装备清单
5. 应急演练计划

## 七、监督检查与法律责任

### （一）监督检查

交通运输主管部门和公安机关交通管理部门依法对危险货物道路运输实施监督检查：

1. 检查企业资质条件
2. 检查车辆技术状况
3. 检查从业人员资格
4. 检查运输作业规范
5. 检查安全管理制度落实情况

### （二）法律责任

| 违法行为 | 处罚措施 |
|---------|---------|
| 未取得许可擅自从事危险货物运输 | 责令停止经营，没收违法所得，处违法所得2-10倍罚款 |
| 使用无资质车辆运输危险货物 | 责令改正，处1-5万元罚款 |
| 驾驶人员无从业资格证 | 责令改正，处200-2000元罚款 |
| 超载运输危险货物 | 责令改正，处1-3万元罚款 |
| 未按规定路线行驶 | 责令改正，处500-3000元罚款 |

## 八、应急处置

### （一）事故报告

发生危险货物运输事故后，驾驶人员和押运人员应当立即采取应急处置措施，并向以下部门报告：

1. 公安机关（110）
2. 消防救援机构（119）
3. 交通运输主管部门
4. 生产经营单位

### （二）现场处置

1. **疏散人员**：立即疏散事故现场及周边人员
2. **划定警戒区**：根据危险货物性质划定警戒区域
3. **采取防护措施**：佩戴防护装备，防止中毒和灼伤
4. **控制泄漏源**：采取措施控制危险货物泄漏
5. **环境保护**：采取措施防止环境污染

### （三）常见危险货物应急处置

| 危险货物类型 | 应急处置要点 |
|------------|------------|
| 易燃液体 | 切断火源，使用泡沫、干粉灭火器灭火 |
| 腐蚀性物质 | 使用大量水冲洗，防止流入下水道 |
| 毒性物质 | 佩戴防毒面具，向上风方向疏散 |
| 爆炸品 | 远离现场，等待专业人员处置 |
| 气体泄漏 | 切断气源，使用雾状水稀释 |

## 十、结语

危险货物道路运输管理是保障公共安全的重要工作。运输企业应当严格落实安全生产主体责任，加强从业人员培训，规范运输作业行为，完善应急预案，确保危险货物运输安全。各级交通运输主管部门和公安机关交通管理部门应当加强监督检查，严厉打击违法行为，维护危险货物运输市场秩序，保障人民群众生命财产安全和环境安全。
